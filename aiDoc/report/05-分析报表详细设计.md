## 一、功能概述

### 1.1 功能定位

与 Excel 报表（画布式、格式精确）**互补**的配置式多维分析报表：用 **AntV S2**（Canvas 渲染的交叉分析表格）替换 Univer，"配置行头/列头/数值列/聚合方式/样式 → 实时预览 → 保存配置 → 按配置展示"。每个分析报表**绑定且仅绑定 1 个数据集**；聚合发生在**前端**（S2 2.x 不聚合重复维度行，自建聚合层预计算），后端仅提供明细取数。

### 1.2 功能范围

**含**：

1. 分析报表 CRUD（元数据 + `set_code` 单选数据集）、复制（元数据+配置深拷贝）、启用/禁用；
2. 配置保存 `saveAnalysisConfig`（JSON 校验 + sheetType/aggregation 枚举校验 + **字段白名单校验**）；
3. 预览取数 `previewAnalysisReport`：返回单数据集**明细** + 字段类型推断（string/number/date）+ 超限（>50000）回退分页截断置 `truncated=true`；
4. 配置式设计器（列表页内 Tab 承载，三栏）：字段面板（维度/度量分区，点击/拖拽）/ S2 实时预览（配置即渲染）/ 配置面板（数据 Tab + 样式 Tab，含联动规则）；
5. 前端聚合层 `aggregate.js`（rows+columns 分组，每度量 SUM/COUNT/AVG/MIN/MAX/NONE 计算派生列）+ 配置映射 `s2Config.js`；
6. 预览页（参数表单逻辑与 04 预览页一致——建议抽公共组件 `paramForm.vue` 共用 + S2 渲染 + S2 内置分页 + 截断提示）；
7. 数据集删除引用校验补齐（`report_analysis_reports.set_code` 等值引用 → 02 `ErrSetReferencedByReport`）；
8. **添加到菜单**（实装已交付）：设计器工具栏 AddToMenuModal → 前端调 GVA 菜单新增 API 创建指向分析预览页并携 reportCode 的菜单（GVA 适配沿用 03 §5.8 path 内嵌 query 机制）。

**不含**：导出 Excel/PDF（S2 export API 后续迭代）、服务端聚合/OLAP 预计算、多数据集关联、自定义主题调色板、分享/调度。

## 二、术语与业务规则

| 术语 | 含义 |
|---|---|
| 行头/列头（rows/columns） | 透视表行/列分组维度（有序，首个为最外层），仅维度字段（string/date） |
| 数值列（values） | `[{field, aggregation, alias?, format?}]`；聚合 SUM/COUNT/AVG/MIN/MAX/**NONE**（NONE=SQL 已预聚合字段直显，防重复求和） |
| 派生键 | 前端聚合产物列名 `${field}__${aggregation}`（同字段可配多种聚合不冲突） |
| 数值置于（valueInRow） | 配置 JSON 用户语义布尔；S2 实际属性为 `valueInCols`（映射层取反） |
| 视图（sheetType） | `pivot` 透视 / `table` 明细（明细模式列 = rows 顺序 + values 字段，禁用行头列头/小计/冻结行头） |
| 配置 JSON | 设计器保存物：`{sheetType, fields{rows,columns,values,valueInRow}, options{pagination,frozenRowHeader,showSeriesNumber,hierarchyType,layoutWidthType,adaptive,totals,style?}, theme{name}}` 三段 |
| truncated | 预览取数超 50000 行截断标志（前端警示条，不阻断） |

**核心业务规则**：

1. **reportCode 全局唯一**；`setCode` 必填、存在且已启用；**更换数据集**后已存配置大概率失效（前端强提示「配置将失效，需重新设计」，确认后才提交）；
2. **saveConfig 三层校验**：JSON 可解析 → `sheetType/aggregation` 枚举合法 → `fields.rows/columns/values[].field` ⊆ 数据集字段白名单（白名单优先取 `case_result` 首行 keys；为空跳过——设计器字段本就来自实时 preview，白名单是纵深防御）；
3. **聚合在前端**：后端 preview 只回明细（≤50000 或截断），S2 收到的是按维度组合唯一化的聚合行（§5.5）；
4. **分页**：S2 内置 `options.pagination`（透视按行头节点、明细按数据行）；改 pageSize/行头/列头/数值后 `current` 重置 1（前端联动）；
5. **小计/总计语义限制**：S2 `calcSubTotals/calcGrandTotals` 为维度级全局 SUM——SUM 列精确，AVG 列是"平均的平均"，NONE 列也会被求和；界面提示注明，精确汇总引导 SQL 预聚合；
6. **删除级联**：删报表 → 级联删配置；删数据集 → 被 `set_code` 等值引用即拒（02 错误码，本期落地）。

## 三、数据库设计

迁移 `000010_create_report_platform` 中本功能两张表：

```sql
-- 分析报表元数据
CREATE TABLE IF NOT EXISTS report_analysis_reports (
    id           bigserial     PRIMARY KEY,
    report_code  varchar(100)  NOT NULL,
    report_name  varchar(100)  NOT NULL DEFAULT '',
    report_group varchar(100)  NOT NULL DEFAULT '',
    report_desc  varchar(255)  NOT NULL DEFAULT '',
    set_code     varchar(50)   NOT NULL DEFAULT '',   -- 关联数据集（单选）→ report_data_sets.set_code
    status       smallint      NOT NULL DEFAULT 0,    -- 0启用 1禁用
    created_by   varchar(64)   NOT NULL DEFAULT '',
    updated_by   varchar(64)   NOT NULL DEFAULT '',
    created_at   timestamptz   NOT NULL DEFAULT now(),
    updated_at   timestamptz   NOT NULL DEFAULT now(),
    deleted_at   timestamptz
);
COMMENT ON TABLE report_analysis_reports IS '报表平台-分析报表元数据表';
CREATE UNIQUE INDEX IF NOT EXISTS uk_report_analysis_code
    ON report_analysis_reports (report_code) WHERE deleted_at IS NULL;
CREATE INDEX IF NOT EXISTS idx_report_analysis_set
    ON report_analysis_reports (set_code) WHERE deleted_at IS NULL;

-- 分析报表配置内容（与元数据按 report_code 1:1）
CREATE TABLE IF NOT EXISTS report_analysis_configs (
    id          bigserial    PRIMARY KEY,
    report_code varchar(100) NOT NULL,
    config_json text,                                 -- S2 配置 JSON（fields/options/theme 三段）
    set_param   text,                                 -- 参数默认值 JSON（预留，与 Excel 模板对称）
    created_by  varchar(64) NOT NULL DEFAULT '',
    updated_by  varchar(64) NOT NULL DEFAULT '',
    created_at  timestamptz NOT NULL DEFAULT now(),
    updated_at  timestamptz NOT NULL DEFAULT now(),
    deleted_at  timestamptz
);
COMMENT ON TABLE report_analysis_configs IS '报表平台-分析报表配置内容表';
CREATE UNIQUE INDEX IF NOT EXISTS uk_report_analysis_config_code
    ON report_analysis_configs (report_code) WHERE deleted_at IS NULL;
```

### 4.5 字段类型推断（inferColumns）

```go
type ColumnMeta struct {
	Name string `json:"name"`
	Type string `json:"type"` // string / number / date
}
// 规则（v1.2 终态语义）：
// · number：前 50 行非空样本中 ≥80% 可转数字（数值类型直判；字符串用 strconv.ParseFloat——
//   支持小数/负数/科学计数法；容忍空值）
// · date：非 number 且首行值匹配 ^\d{4}[-/]\d{1,2}[-/]\d{1,2}.*$
// · 其余 string
// 用途：设计器字段面板维度/度量分区（number→度量候选，string/date→维度候选）；
```

## 九、风险与注意事项

| 风险 | 等级 | 应对 |

| SQL 已聚合字段被重复求和 | 中 | NONE 聚合方式 + 字段面板提示（§5.7） |
| 配置 JSON 结构演进 | 低 | loadConfig 与 defaultConfig 逐层合并兜底，新字段带默认值不破坏旧配置 |
| S2 2.x breaking change | 中 | pin patch + lockfile；不自动升级 |

**复用（零改造/范式复用）**：数据源/数据集管理全套；`Query/QueryPage`（SELECT-only+参数预编译+转换器+上限）；`fillDefaultParamValues`（02/04，参数按数据集各自解析）；参数表单逻辑（04 预览页，建议抽公共 `paramForm.vue`）；列表+页内设计器 Tab 范式（03 列表页交互）；hidden 菜单 + path 内嵌 query 范式（03/04）；「添加到菜单」弹窗范式（03）。
