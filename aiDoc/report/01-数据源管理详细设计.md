## 一、功能概述

### 1.1 功能定位

数据源管理是报表平台的**取数底座**：管理报表可用的外部数据库连接配置（业务库、统计库、第三方库等，不受本程序业务库仅用 PostgreSQL 的限制）。两样核心资产：

1. **数据源连接配置**——`{dsn, username, password}` JSON，密码 AES-GCM 加密落库、脱敏回显；
2. **连接池管理器 `DataSourcePoolManager`**——按 `sourceCode` 缓存各数据源的 `*sql.DB`，按 `sourceType` 适配驱动注册与验证 SQL；数据源配置变更/删除时销毁旧池。02 数据集查询完全复用本管理器。

### 1.2 功能范围

**含**：

1. 数据源 CRUD：分页查询（keyword + sourceType + enableFlag）、详情、创建、更新、删除；
2. 数据源编码唯一校验（Service 预查重 + DB 部分唯一索引兜底）；
3. 密码 AES-GCM 加密存储 / 脱敏返回 / 编辑留空保留原密码；
4. 测试连接（临时建连接执行验证 SQL，不污染连接池缓存）；
5. 已启用数据源全量下拉（`getDataSourceAll`，供 02 数据集编辑选择）；
6. 连接池管理器（getOrCreate / remove / testConnection）；
7. 删除引用校验**埋点**（被数据集引用时拒绝删除——02 落地后启用，本期先留校验函数空位）。

**不含**：数据集管理（02）、报表/设计器/预览（03~05）、Oracle（需 CGO，默认不启用，见 §1.3）、Elasticsearch 等非关系型数据源。

### 1.3 与参考设计的差异裁定

## 二、术语与业务规则

| 术语 | 含义 |
|---|---|
| sourceCode | 数据源编码，全局唯一，`^[a-zA-Z0-9_]+$`，≤50 字符；被数据集引用后**不可修改**（编辑禁用） |
| sourceType | 数据源类型标识：`postgresql / mysql / sqlserver / mariadb / dameng / kingbase / opengauss / highgo / shentong / gbase / oracle / http`（本期开箱 postgresql/mysql/sqlserver，http 类型无连接配置） |
| dsn | Go database/sql 数据源名，因类型而异（PG：`postgres://host:port/db`；MySQL：`user:pass@tcp(host:port)/db`；SQLServer：`sqlserver://user:pass@host:port?database=db`） |
| sourceConfig | 连接配置 JSON 字符串 `{dsn, username, password}`，password 字段**密文**存储 |
| enableFlag | 启用状态；禁用的数据源不出现在 02 数据集编辑下拉中，取数时报「数据源已禁用」 |

**核心业务规则**：

1. **sourceCode 全局唯一**（软删后可复用）：Service 预查重（编辑排除自身）+ 部分唯一索引兜底；
2. **sourceType 编辑不可改**（影响驱动注册与连接池），sourceCode 编辑不可改（被引用后改名断链）；如需变更类型，新建数据源；
3. **密码三态**：新建必填（可空密码库也允许空串）；编辑时前端回显 `******`，提交 `******` 或空 → 保留原密文；提交新值 → 加密替换；
4. **测试连接**：请求体直接传配置（前端当前表单值，不先保存）；HTTP 类型直接返回成功；临时 `sql.Open` + `PingContext(5s)` 后关闭，**不写入池缓存**；
5. **连接池生命周期**：创建/查询时 `getOrCreate`（按 sourceCode 惰性建池）；更新/删除时 `remove(sourceCode)` 关闭旧池（下次取数自动重建）；
6. **删除保护**：被 `report_data_sets.source_code` 引用时拒绝删除（02 落地启用；本期 `validateNotReferenced` 返回 nil 占位）。

### 4.4 连接池管理器（service/report/pool.go）

```go
type DataSourcePoolManager struct {
	pool sync.Map // sourceCode → *sql.DB
}

// GetOrCreate 获取或创建连接池（sourceConfig 中 password 须已解密）
func (m *DataSourcePoolManager) GetOrCreate(sourceCode, sourceType, sourceConfig string) (*sql.DB, error) {
	if db, ok := m.pool.Load(sourceCode); ok {
		return db.(*sql.DB), nil
	}
	spec, ok := driverRegistry[sourceType]
	if !ok || !spec.enabled {
		return nil, ErrSourceDriverDisabled
	}
	dsn, err := buildDsn(sourceConfig) // 解析 JSON {dsn,username,password}，独立凭据优先拼入 dsn
	if err != nil {
		return nil, ErrSourceConfigInvalid
	}
	db, err := sql.Open(spec.driverName, dsn)
	if err != nil {
		return nil, fmt.Errorf("%w: %v", ErrSourceConnFailed, err)
	}
	db.SetMaxOpenConns(5)
	db.SetMaxIdleConns(1)
	db.SetConnMaxLifetime(30 * time.Minute)
	ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
	defer cancel()
	if err := db.PingContext(ctx); err != nil {
		_ = db.Close()
		return nil, fmt.Errorf("%w: %v", ErrSourceConnFailed, err)
	}
	actual, _ := m.pool.LoadOrStore(sourceCode, db)
	return actual.(*sql.DB), nil
}

// TestConnection 测试连接（临时连接，不污染池缓存；调用方负责 Close）
func (m *DataSourcePoolManager) TestConnection(sourceType, sourceConfig string) error { /* sql.Open + PingContext(5s) + Close */ }

// Remove 数据源配置变更/删除时关闭旧池
func (m *DataSourcePoolManager) Remove(sourceCode string) {
	if db, ok := m.pool.LoadAndDelete(sourceCode); ok {
		_ = db.(*sql.DB).Close()
	}
}
```

**关键设计决策**（与参考一致）：① 按 sourceCode 缓存，驱动按 sourceType 适配；② `GetOrCreate` 建池即 `Ping`（10s 超时）拦截坏配置；③ `TestConnection` 独立于池缓存；④ 配置变更必须 `Remove`（Service 层负责调用）。

### 4.5 密码加解密（service/report/crypto.go）

- AES-256-GCM；密钥来自 `global.GVA_CONFIG.Report.AesKey`（config.yaml `report.aes-key`，32 字节 base64）；
- 密文格式：`enc:` + base64(nonce(12B) + ciphertext+tag)；
- `EncryptPassword(sourceConfig)` / `DecryptPassword(sourceConfig)`：解析 JSON→仅替换 `password` 字段→回写 JSON（保持字段序）；
- `MaskPassword(sourceConfig)`：password → `******`（供 RespVO）；
- `HandlePasswordOnUpdate(id, sourceConfig)`：提交值为空或 `******` → 从库中原密文原样保留；否则加密替换；
- 启动校验：`AesKey` 非法（非 32 字节）时 `fmt.Errorf` 拒绝启动（在 config 校验/SeedReport 前置检查），拒绝明文落库。

`config/config.go` 新增：

```go
type Report struct {
	AesKey string `mapstructure:"aes-key" json:"aes-key" yaml:"aes-key"` // 数据源密码加密密钥（32字节base64）
}
// config.go 的 Server 结构体追加 Report Report `mapstructure:"report" json:"report" yaml:"report"`
```

config.yaml 追加：

```yaml
report:
  aes-key: ""  # 32字节随机数的base64，生成：openssl rand -base64 32；必填
```

| GET | `/report/dataSource/getDataSourceList` | 分页 | query：page/pageSize/keyword/sourceType/enableFlag；响应 `response.PageResult`（sourceConfig 已脱敏） |
| GET | `/report/dataSource/findDataSource` | 详情 | query：ID；响应单条（脱敏） |
| POST | `/report/dataSource/createDataSource` | 新增 | body：模型 JSON（sourceConfig 明文，后端加密） |
| PUT | `/report/dataSource/updateDataSource` | 更新 | body：模型 JSON（含 ID；密码 `******`/空=保留） |
| DELETE | `/report/dataSource/deleteDataSource` | 删除 | query：ID |
| GET | `/report/dataSource/getDataSourceAll` | 已启用全量下拉 | 响应数组（不含 sourceConfig） |
| POST | `/report/dataSource/testDataSourceConnection` | 测试连接 | body：TestConnectionReq；成功 `OkWithMessage("连接成功")`，失败 `FailWithMessage(err)` |

### 4.9 路由（router/report/data_source.go）

```go
func (r *DataSourceRouter) InitDataSourceRouter(Router *gin.RouterGroup) {
	priv := Router.Group("report")
	write := priv.Group("dataSource").Use(middleware.OperationRecord())
	read := priv.Group("dataSource")
	{
		write.POST("createDataSource", dsApi.CreateDataSource)
		write.PUT("updateDataSource", dsApi.UpdateDataSource)
		write.DELETE("deleteDataSource", dsApi.DeleteDataSource)
	}
	{
		read.GET("getDataSourceList", dsApi.GetDataSourceList)
		read.GET("findDataSource", dsApi.FindDataSource)
		read.GET("getDataSourceAll", dsApi.GetDataSourceAll)
		read.POST("testDataSourceConnection", dsApi.TestConnection) // 查询性质，不记操作日志
	}
}
```

## 九、风险与注意事项

| 风险 | 等级 | 应对 |
|---|---|---|
| Go 信创驱动成熟度 | 中 | 本期开箱仅 pg/mysql/sqlserver（go.mod 已有）；达梦/金仓/openGauss 纯 Go 驱动按需启用并单独验证；highgo/shentong/gbase 仅枚举预留 |
| Oracle 需 CGO | 中 | 默认不启用；确有需求时评估 godror（需 Oracle Instant Client）或独立取数服务 |
| AES 密钥管理 | 中 | 密钥仅存 config.yaml（部署侧保密管理）；遗失密钥则旧密文不可解，需重录密码；密文自识别 `enc:` 前缀，支持未来换钥迁移 |
| `*sql.DB` 句柄泄漏 | 低 | 唯一入口 GetOrCreate（LoadOrStore 防并发重建）；Update/Delete 必须 Remove；AC4 专项验证 |
| dsn 拼接凭据注入 | 低 | dsn 由用户配置属受信字段；独立 username/password 优先；配置 JSON 校验必含 dsn 或 apiUrl |
| sourceConfig 2048 长度 | 低 | dsn 超长（含大量参数）时前端 maxlength 提示；库表 2048 足够常规场景 |
