## 一、功能概述

### 1.1 功能定位

数据集是数据绑定的核心桥梁：基于数据源定义查询（SQL / HTTP 两种类型）+ 动态参数 + 数据转换，为 03/04（Excel 报表拖拽绑定与渲染取数）和 05（分析报表取数）提供统一取数能力。四样核心资产：

1. **主子表模型**——数据集主表 + 参数子表 + 转换子表（`set_code` 关联，事务内先删后插）；
2. **`SqlParamResolver`**——`${param}` 参数化防注入（SELECT-only 校验 / 危险词拦截 / `<if>` 条件剥离 / 多选展开 / 占位符 rebind）；
3. **查询执行服务 `DataSetQueryService`**——SQL 多库执行 + HTTP 取数 + 转换链执行 + 行数上限 + 服务端分页（04/05 复用）；
4. **默认值动态表达式解析 `DefaultValueResolver`**——today/now/thisMonth 等 8 种表达式后端实时计算，dateRange 拆 `_start`/`_end`。

### 1.2 功能范围

**含**：

1. 数据集 CRUD（主子表事务保存：先删子表再插）、分页查询、详情（含参数+转换）、已启用全量下拉；
2. 参数配置：7 种参数类型（string/number/date/datetime/dateRange/select/multipleSelect），必填/示例值/默认值表达式/字典与自定义选项（下拉类）/日期格式；
3. 数据转换：`js`（goja 沙箱）与 `dict`（字段值映射）两种执行器，按 orderNum 串行；
4. 测试预览（两种场景：已保存数据集 / 编辑中即时测试）：**走 `QueryPage` 服务端分页**（pageNo/pageSize，默认 1/20），返回 `{data(本页), total, fields, pageNo, pageSize}`；预览面板为服务端分页表格；
5. **演示数据集种子**（并入迁移 000010 尾部）：`sys_users` 查询数据集（含 `${param}` 与 `<if param>` 条件语法）等样例，**携带 `case_result`**——case_result 是 03 设计器左栏字段与 05 白名单的数据来源，实现**无 UI 维护入口**（「保存为案例」列后续迭代），由种子/DBA 维护；
6. 参数默认值表达式解析（后端）；
6. 补齐 01 的数据源删除引用校验（`validateNotReferenced`）；预留数据集删除引用校验（03/05 落地）。

**不含**：报表设计器/预览/导出（03~05）、参数 JS 校验规则执行（`validation_rules` 字段入库预留，前端仅做必填+类型校验，差异裁定见 §1.3）、SQL 动态下拉选项来源、javaBean/Groovy 转换。

### 1.3 与参考设计的差异裁定

| # | 芋道 M2 设计 | 本项目落地（**采用**） | 裁定说明 |
|---|---|---|---|

## 二、术语与业务规则

| 术语 | 含义 |
|---|---|
| setCode | 数据集编码，全局唯一，`^[a-zA-Z0-9_]+$` ≤50；被报表引用后不可修改（编辑禁用） |
| setType | `sql`（关联数据源执行 SQL）/ `http`（直接配置 HTTP 请求，不依赖数据源） |
| dynSentence | 查询语句：SQL 文本（含 `${param}`、`<if param="x">…</if>`）或 HTTP 请求配置 JSON `{apiUrl, method, headers, body}` |
| 参数 `${paramName}` | 查询参数占位符，SQL 场景转预编译占位符传值；HTTP 场景做字符串/深替换 |
| dateRange 拆分 | 日期范围参数在 SQL 中以 `${p_start}`/`${p_end}` 引用，取值时拆两个标量注入 |
| `<if param="x">` | 条件片段：x 为空（null/空白）时整段剥离，非空时保留片段内容参与参数化 |
| caseResult | 结果案例 JSON（数据样例行），03 设计器左栏字段来源、05 保存白名单来源；**由演示种子/DBA 维护**（测试预览不写 case_result，「保存为案例」入口列后续迭代，对齐实现） |
| transform | 数据转换：`js`（脚本，输入 `data` 输出新数组）/ `dict`（`{"field":"x","mapping":{"0":"停用"}}` 字段值映射），按 orderNum 串行 |

**参数类型与录入组件映射**（03/04/05 预览参数表单共用）：

| 参数类型 | 标识 | 前端组件（element-plus） | 默认值表达式 |
|---|---|---|---|
| 文本 | `string` | `el-input` | 直接填文本 |
| 数字 | `number` | `el-input-number` | 填数字 |
| 日期 | `date` | `el-date-picker`（date，`YYYY-MM-DD`） | `today` 或固定日期 |
| 日期时间 | `datetime` | `el-date-picker`（datetime） | `now` 或固定值 |
| 日期范围 | `dateRange` | `el-date-picker`（daterange） | `thisMonth/thisWeek/thisYear/lastMonth/last7Days/last30Days` 或 `起,止` |
| 下拉单选 | `select` | `el-select` | 选项 value；选项来源=字典类型或自定义 JSON |
| 下拉多选 | `multipleSelect` | `el-select multiple` | 逗号分隔 value（SQL 中展开 `IN (?,?,…)`） |

**核心业务规则**：

1. **setCode 全局唯一**；setType 编辑不可改（影响查询逻辑）；sourceCode 仅 sql 类型必填且须存在、启用；
2. **参数名数据集内唯一**、非空、类型合法；`<if>`/`${}` 中引用的参数名未定义时**警告不阻断**（前端提示，后端不校验）；
3. **SQL 三层防注入**：① 去注释后必须 SELECT 开头；② 危险词拦截 `\b(DROP|DELETE|UPDATE|INSERT|TRUNCATE|ALTER|CREATE|GRANT|REVOKE|MERGE|CALL|EXEC|EXECUTE)\b`（忽略大小写，校验 `<if>` 剥离**前**的原文）；③ `${}`→预编译占位符 + args 传值（根本防线）；
4. **行数上限**：单次查询 ≤50000 行（`ErrSetResultTooLarge`）；测试预览走分页不受此影响（queryPage）；
5. **删除级联**：删数据集 → 级联软删参数/转换子表；数据集被 Excel 模板 `set_codes` 或分析报表 `set_code` 引用时拒绝删除（03/05 落地，共用 `ErrSetReferencedByReport`）；
6. **http 类型**：method 默认 GET；响应解析优先级：JSON 数组 → 对象的 `data` 数组 → 对象本身单行；`<if>`/`${}` 替换对 URL/header/body 深度生效。

### 4.3 SqlParamResolver（sql_param_resolver.go，Go 移植）

```go
var (
	paramPattern  = regexp.MustCompile(`\$\{(\w+)\}`)
	ifPattern     = regexp.MustCompile(`(?s)<if\s+param="(\w+)"\s*>(.*?)</if>`)
	dangerPattern = regexp.MustCompile(`\b(DROP|DELETE|UPDATE|INSERT|TRUNCATE|ALTER|CREATE|GRANT|REVOKE|MERGE|CALL|EXEC|EXECUTE)\b`)
	selectStart   = regexp.MustCompile(`(?is)^\s*(--[^\n]*\n|\s|/\*.*?\*/)*SELECT\b`)
)

// ValidateSQL SELECT-only + 危险词拦截（在 <if> 剥离前的原文上执行）
func ValidateSQL(sql string) error

// StripEmptyIfBlocks 参数为空(null/空白)的 <if> 整段删除；非空仅保留内容；仅支持单层不嵌套
func StripEmptyIfBlocks(sql string, values map[string]interface{}) string

// ResolvedSQL 解析产物
type ResolvedSQL struct {
	Query string        // 含 ? 占位符（未 rebind）
	Args  []interface{} // 与占位符顺序一致
}

// Resolve ${p} → ?；值缺省为 ""；逗号分隔字符串展开为 ?,?,…（IN 场景）
func Resolve(sqlText string, values map[string]interface{}) (*ResolvedSQL, error)

// RebindDollar ? → $1..$N（PG 系驱动），其余驱动原样
func RebindDollar(query string) string

// ReplaceParams / ReplaceParamsDeep HTTP 场景的纯字符串/深替换（非预编译）
func ReplaceParams(text string, values map[string]interface{}) string
```

**执行链**：`ValidateSQL(原文)` → `StripEmptyIfBlocks` → `Resolve`（产出 `?` 占位符 + args）→ 执行前按 `driverRegistry[sourceType].rebindDollar` 决定是否 `RebindDollar`。

**多选展开示例**：` workshop IN (${workshops}) `，`workshops="WS001,WS002"` → ` workshop IN (?,?) ` + args=[WS001,WS002]。

### 4.5 查询执行服务（query.go）

```go
type QueryResult struct {
	Columns []string                 // 列序（SELECT 输出顺序）
	Rows    []map[string]interface{} // 行数据
}

type DataSetQueryService struct{ /* 依赖 dataSourceService */ }

// Execute 按类型分发（编辑中即时测试用：直接传配置）
func (q *DataSetQueryService) Execute(setType, sourceCode, dynSentence string,
	paramValues map[string]interface{}, transforms []report.ReportDataSetTransform) (*QueryResult, error)

// Query 按已保存数据集执行（查库组装 → 必填校验 → Execute → 转换链）
func (q *DataSetQueryService) Query(setCode string, paramValues map[string]interface{}) (*QueryResult, error)

// QueryPage 服务端分页（04 预览主数据集分页 / 05 超限回退用）
// page 从 1 起；total 由 COUNT 包装 SQL 求得；含转换器的数据集走「全量查询 + 内存分页」
func (q *DataSetQueryService) QueryPage(setType, sourceCode, dynSentence string,
	paramValues map[string]interface{}, page, pageSize int,
	transforms []report.ReportDataSetTransform) (result *QueryResult, total int64, err error)
```

**ExecuteSQL 流程**：

```
① ValidateSQL → ② 取数据源（存在+启用）→ ③ DecryptPassword(sourceConfig) → Pool.GetOrCreate
④ StripEmptyIfBlocks → Resolve（? + args）→ rebind → db.QueryContext(30s)
⑤ 逐行扫描 sql.Rows：Columns() 记列序，行转 map（数值/时间驱动态，json.Marshal 兼容）
⑥ 行数 ≥50000 → ErrSetResultTooLarge
```

**QueryPage 分页方言**（`pageFrom1`）：

| 驱动系 | 包装 SQL |
|---|---|
| pg 系 / mysql（LIMIT 语法） | `SELECT * FROM ( 原SQL去尾分号 ) t LIMIT ? OFFSET ?`；count：`SELECT COUNT(*) FROM ( 原SQL ) t` |
| sqlserver | `SELECT * FROM ( 原SQL ) t ORDER BY (SELECT NULL) OFFSET ? ROWS FETCH NEXT ? ROWS ONLY` |
| 含转换器 | 不改写 SQL：全量 Execute（受 50000 上限）→ 内存切片 + len 为 total |

**ExecuteHTTP 流程**：解析 `{apiUrl, method=GET, headers{}, body{}}` → `ReplaceParams`（URL/headers）+ `ReplaceParamsDeep`（body）→ `http.Client{Timeout:30s}`（`net.Dialer` 连接 10s）→ 2xx 外报 `ErrSetHttpFailed` → 响应解析（数组 / `.data` 数组 / 单对象）→ QueryResult（首行 keys 为 Columns）。

### 4.6 转换执行器（transform.go）

```go
type TransformExecutor interface {
	Support(transformType string) bool
	Execute(result *report.QueryResult, script string) (*report.QueryResult, error)
}

// JsTransformExecutor —— goja 沙箱
func (e *JsTransformExecutor) Execute(result *QueryResult, script string) (*QueryResult, error) {
	vm := goja.New()
	vm.SetFieldNameMapper(goja.TagFieldNameMapper("json", true))
	_ = vm.Set("data", result.Rows)                 // 唯一注入：行数据数组；无任何宿主函数/IO
	timer := time.AfterFunc(3*time.Second, func() { vm.Interrupt("execution timeout") })
	defer timer.Stop()
	v, err := vm.RunString("(function(data){ " + script + " })(data)")
	if err != nil { return nil, fmt.Errorf("%w: %v", ErrSetTransformFailed, err) }
	// 返回值须为数组 → 重建 QueryResult（Columns 取首行 keys 并集，保持原列序在前）
}

// DictTransformExecutor —— {"field":"status","mapping":{"0":"停用","1":"启用"}} 字段值映射（未命中保持原值）
```

**goja 沙箱要点**：① 每次执行新建 `Runtime`（无状态复用）；② 仅 `Set("data", …)`，不注册 `require/console/fs` 等任何对象——语言层无宿主可达，无文件/网络/协程能力；③ 3s `Interrupt` 防死循环；④ 返回值类型校验（数组，元素为对象）。

## 九、风险与注意事项

| 风险 | 等级 | 应对 |
|---|---|---|
| goja ES 版本差异（ES5.1+部分 ES6） | 中 | 文档与脚本占位示例限定箭头函数/展开语法可用（goja 支持 ES2017 大部分）；极端语法在测试预览即时暴露 |
| SQL 防注入正则被绕过 | 中 | 参数化传值是根本防线；正则仅第一道；AC6 用注入向量集做单测；子查询包裹分页不改语义（外层仅 SELECT *） |
| 分页包装 SQL 方言兼容 | 中 | 仅三类开箱驱动各写用例验证；ORDER BY 在子查询内保留；sqlserver 用 `ORDER BY (SELECT NULL)` 绕开强制排序 |
| `<if>` 与 `${}` 嵌套边界 | 低 | 仅支持单层 `<if>`、片段内可含 `${}`（先剥离后参数化）；嵌套 `<if>` 文档明示不支持 |
| 转换器 + 分页内存放大 | 中 | 含转换器的 QueryPage 走全量（受 50000 上限）；04/05 场景引导数据集 SQL 预聚合 |
| HTTP 响应结构不可预期 | 低 | 解析规则固定三档（数组/.data/单对象）；失败信息带 HTTP 状态码与响应前 200 字符 |
| 子表先删后插的 ID 抖动 | 低 | 子行 ID 不被外部引用（设计如此）；主表 ID 稳定 |
