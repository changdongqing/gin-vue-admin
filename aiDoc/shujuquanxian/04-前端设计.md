# 04 前端设计

前端：`web/`（Vue 3 `<script setup>` + Element Plus + vxe-table/GvaGrid）。页面全部走后端菜单动态路由，**不需要改 router**——菜单由种子数据写入 `sys_base_menus`，组件路径按 `view/**` 解析。

## 1. 文件清单

```
web/src/
├── api/
│   ├── company.js                    # 公司 API
│   ├── department.js                 # 部门 API
│   └── authority.js                  # 修改：+setDataScope/getDataScope
├── view/superAdmin/
│   ├── company/company.vue           # 公司管理页
│   ├── department/department.vue     # 部门管理页
│   ├── authority/authority.vue       # 修改：新增「数据权限」Tab
│   ├── authority/components/
│   │   └── dataScope.vue             # ★ 角色数据权限配置组件
│   └── user/user.vue                 # 修改：部门列 + 表单主属部门选择
```

页面组件必须 `defineOptions({ name: 'Company' })` 等，与菜单 name 一致（keep-alive 依赖）。

## 2. 公司管理页（company.vue）

复用角色管理页的 **GvaGrid 树表** 模式：

- `useGvaGrid({ id: 'superAdmin-company', pager: false, defaultSort: null, api: getCompanyList, gridConfig: { treeConfig: { rowField: 'ID', children: 'children' } } })`
- 列：公司名称（`treeNode: true`）、编码、负责人、电话、排序、状态（`el-switch`）、层级、创建时间、操作（新增子级 / 编辑 / 删除）
- 工具栏：「新增公司」按钮
- 新增/编辑抽屉（`el-drawer` + `appStore.drawerSize`，头部取消/确定按钮，风格同用户管理）：
  - 父级公司：`el-cascader`（checkStrictly + emitPath:false，选项由树递归生成，编辑时禁选自身及子孙）
  - 公司名称 / 编码 / 负责人 / 电话 / 邮箱 / 地址 / 排序 / 状态 / 备注
- 删除：`ElMessageBox.confirm`，后端有子孙/部门保护，错误信息直出
- 搜索：公司名称关键字（后端 `name` 参数，平铺结果）

## 3. 部门管理页（department.vue）

- 结构同公司管理，额外字段：
  - **所属公司**：`el-tree-select`（公司树，node-key=ID，check-strictly），新建时必填
  - 搜索区：所属公司下拉（切换后整棵部门树过滤为该公司）+ 部门名称
- 列：部门名称（treeNode）、编码、所属公司（`row.companyName` 或由前端树映射）、负责人、排序、状态、操作
- 父级部门选择器只展示**同公司**的部门（跨公司不允许父子，后端同样校验）

## 4. 角色数据权限配置（dataScope.vue）

挂在角色管理「设置权限」抽屉中，成为第 4 个 Tab「数据权限」（与 角色菜单/角色api/资源权限 并列，`before-leave` 拦截保存逻辑与既有 Tab 一致）：

```
┌ 数据权限 ────────────────────────────────┐
│ 数据范围  (●) 全部数据                    │
│          ( ) 自定义数据                   │
│          ( ) 本公司数据                   │
│          ( ) 本部门及以下数据              │
│          ( ) 本部门数据                   │
│          ( ) 仅本人数据                   │
│ ┌─────────────────────────────────────┐  │
│ │ 【自定义数据时显示】                   │  │
│ │  Tab: 公司 | 部门                     │  │
│ │  el-tree show-checkbox               │  │
│ │  （勾选公司=整家公司；勾选部门=子树）    │  │
│ └─────────────────────────────────────┘  │
│                            [保 存]        │
└──────────────────────────────────────────┘
```

- 加载：`getDataScope(authorityId)` 回显档位与勾选；保存：`setDataScope({ authorityId, dataScope, companyIds, departmentIds })`
- 档位单选用静态常量（与后端 1-6 对齐），不依赖字典表
- 交互细节：非「自定义」档位时隐藏明细区；`needConfirm` 置位供 `before-leave` 自动保存（同 menus.vue/apis.vue 模式）

## 5. 用户管理改造（user.vue）

1. **部门列**：表格新增「所属部门」列，显示 `row.department?.name ?? '未分配'`（后端 Preload 返回）
2. **表单**：新增「主属部门」`el-tree-select`（部门树，node-key=ID，check-strictly，可清空；清空即 `departmentId=0`）
3. **搜索**：新增部门筛选（可选项，本期列表 API 支持 `departmentId` 参数；页面默认不放树搜索框，保留扩展）
4. 新建/编辑请求体自然携带 `departmentId`（后端 Register/SetUserInfo 已支持）
5. 行内数据权限提示：当用户列表被数据权限过滤时（total 变小属正常现象），不做特殊 UI，由权限语义保证

## 6. 组件与规范要点

- 所有请求走 `@/utils/request` 封装（自动带 `x-token`、统一错误 toast、`code===0` 判定）
- 抽屉宽度统一 `appStore.drawerSize`；表单 `rules` + `resetFields()` 收尾清理
- 树组件统一 `node-key="ID"`、`props: { label: 'name', children: 'children' }`
- 文案全部简体中文硬编码（本项目未启用 i18n，保持一致）
- 列表空态、加载态由 GvaGrid 内置处理

## 7. 菜单与路由（种子数据效果）

| 菜单 | 父级 | path | component | 可见性 |
| --- | --- | --- | --- | --- |
| 公司管理 | 超级管理员 | company | view/superAdmin/company/company.vue | 显示 |
| 部门管理 | 超级管理员 | department | view/superAdmin/department/department.vue | 显示 |

管理员（888）默认拥有上述菜单与全部新 API；其他角色由「角色管理 → 角色菜单 / 角色api」勾选授予。
