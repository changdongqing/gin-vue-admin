## 一、功能概述

### 1.1 功能定位

外部模块关联把**既有业务表**（本库中的 `sys_users`、插件表、自建业务表等）接入本体体系：注册外部模块与表 → 为「可实例化类」配置类级绑定（主表 + 列映射 + 子表 + 属性绑定）→ 试运行预览 → 生效 → 手动触发**全量/增量同步**，把业务行物化为本体对象（含属性值与关系解析）。业务模块**零改动**，业务表始终是权威源（v1 单向只读：业务表 → 本体对象）。

页面为**三 Tab 单页**：

| Tab | 名称 | 职责 |
|---|---|---|
| binding | 类绑定配置 | 绑定列表（草稿/生效/停用）、新建/编辑绑定抽屉、生效/停用、试运行入口 |
| registry | 模块与表 | 外部模块 CRUD + 物理表注册（探测 information_schema，勾选批量注册） |
| sync | 同步中心 | 生效绑定卡片（增量/全量触发）+ 同步日志 |

### 1.2 功能范围

**含**：

1. **注册表（registry）**：外部模块 CRUD（moduleCode/name/serviceName）；表注册——按关键字探测本库 public schema 物理表（含注释、已注册标注），勾选批量注册；探测表列（columnName/dataType/comment），供绑定表单列下拉；
2. **类绑定（binding）**：草稿保存（四段配置：基本信息/子表绑定/属性绑定/策略）、编辑回填（含类属性清单与列缓存还原）、生效（校验链）/停用、删除；
3. **试运行（dry-run）**：按绑定配置取前 N 行（默认 20）只读预览——bizKey/预览编码/预览名称/属性值（转换成败标记）/关系解析（resolved + 目标对象名）+ warnings，不落库不写日志；
4. **同步（sync）**：手动触发全量（含孤儿检测）或增量（水位）；物化 `ont_objects` + 属性值 + 关系；行级计数（created/updated/skipped/failed/issues）+ skipReasons 明细 + 耗时；同步日志分页查询；绑定卡片回显水位/最近同步时间/结果摘要；
5. **对象落地最小模型**：`ont_objects` / `ont_object_attr_values` / `ont_object_relations` 三表（同步写目标；完整对象管理为后续独立需求，本期无对象 CRUD 页面）。

**不含**：双向写同步（业务表只读）、定时调度（syncMode=2 可配置存储，调度器后续需求）、对象管理页面（手工 CRUD/EAV 编辑）、反向实例化弹窗（triggerType=1 预留）、多数据源（仅本库 public schema）。

### 1.3 与参考设计的差异裁定（以前端实现为准）

| # | 《多模块建对象》文档（旧方案） | extbinding 前端实现（**采用**） | 裁定说明 |
|---|---|---|---|
| 1 | 类级映射 = `ont_model_class` 加 biz_* 8 字段，类表单内配置 | **独立注册表 + 绑定表**：模块/表注册（ext-registry）、绑定配置（ext-binding）三域分离；02 类表单**无**业务表映射分区（前端注释「已迁出至 extbinding」） | 02 的类表单不含 biz_*；映射配置全部收敛到本功能 |
| 2 | 一张 `ont_object_mapping`（object_id ↔ biz_table/biz_key） | 绑定主表 + 子表绑定 + 属性绑定三张配置表；映射身份落在同步产物 `ont_objects`（biz_table/biz_key 冗余 + 唯一约束） | 身份一致性语义保留（同类同业务记录一个对象），载体改变 |
| 3 | dry-run = previewBizRows 分页预览 | **DryRunVO**：固定 limit 行 + warnings + 值转换/关系解析逐项标记 | 采前端形态（更完整的预演信息） |
| 4 | 同步 = 反向批量实例化（一次性 created/skipped） | **同步中心**：全量/增量双模式 + 水位 + 孤儿检测 + created/**updated**/skipped/failed/issues 五计数 + 同步日志 | 采前端（持续同步语义，非一次性导入） |
| 5 | 类级 6 个映射列（key/code/name/parent/status + active） | 绑定级同语义 6 列 + 子表绑定（宽/窄表）+ 属性级绑定（值来源/列/转换器/常量值/启用） | 配置粒度细化到属性；列语义沿用 |
| 6 | API `/ontology/object-mapping/*` 4 个 | ext-registry / ext-binding / ext-sync 三组 18 个 | 本项目改造为 `/ontology/extModule/*`、`/ontology/extTable/*`、`/ontology/extBinding/*`、`/ontology/extSync/*` camelCase 动词（见 §4.4） |
| 7 | 编码规则「禁止 name 列当编码、空则 `{类名小写}-{biz_key}`」 | 前端 codeColumn 空提示「=类名-{主键}」 | **规则保留**（防唯一索引冲突，旧文档评审结论继续有效） |
| 8 | 服务端表/列校验直查 information_schema、标识符白名单 + 占位符参数化、escapeLike | 前端不承担校验 | **安全设计全量保留**（§4.3、§5.4） |

## 二、术语与业务规则

| 术语 | 含义 |
|---|---|
| 外部模块（extModule） | 业务表的逻辑分组（如 system/infra/iot），moduleCode 唯一 |
| 表注册（extTable） | 登记一张可绑定的物理表：pkColumn 主键列、deletedColumn 软删列、updateTimeColumn 水位列、supportsIncremental 是否支持增量 |
| 绑定（extBinding） | 类 ↔ 主表的映射配置；bindingStatus：**0 草稿 / 1 生效 / 2 停用**；仅生效绑定可同步 |
| 子表绑定（detail） | detailKind：**1 宽表**（一对一扩展行，值列各存一列）/ **2 窄表**（EAV 一行一属性，identifier 列匹配属性） |
| 属性绑定（propertyBinding） | 类属性 ↔ 列的映射：bindingType 1 数据/2 对象；值来源=主表或宽表子表（窄表用 identifier 匹配值）；enabled 启用 |
| 水位（watermark） | 增量同步起点：最近一次扫描的最大 updateTimeColumn 值 |
| 孤儿（orphan） | 全量同步时已物化对象对应的业务行已不存在（含软删）→ state=3 失联，计 issue，不物理删除 |
| 值漂移（conflict） | 已物化对象的值与业务表当前值不一致；conflictStrategy：**2 业务表覆盖（默认）/ 1 仅报告** |
| 目标缺失（missingTarget） | 父节点/关系解析找不到目标对象；missingTargetPolicy：**1 跳过并记 issue（默认）/ 2 整行失败** |
| 触发类型 | triggerType：1 反向实例化（预留）/ 2 手动（同步中心）/ 3 定时（预留）/ 4 试运行（预留） |
| 同步范围 | syncScope：1 全量（含孤儿检测）/ 2 增量（水位） |

**核心业务规则**：

1. **注册表规则**：moduleCode 全局唯一；**物理表全局至多注册一次**（probe 的「已注册」标注 + checkbox 禁选即此语义）；有表注册的模块不可删除；被绑定引用的表不可删除；
2. **绑定准入**：仅 `isInstantiable=1` 的类可绑定（前端过滤 + 后端校验）；**一个类至多一条生效绑定**（部分唯一索引），草稿可多条；绑定保存即草稿态（bindingStatus=0），生效需显式操作；
3. **生效校验链**（changeExtBindingStatus → 1）：项目未归档 → keyColumn 在主表列集内 → 配置的 code/name/parent/status 列均存在 → 每条启用属性绑定的 bizColumn 在其值来源表列集内（窄表来源为匹配值不校验列）→ 每条子表绑定的 joinColumn/值列在其子表列集内 → statusColumn 与 statusActiveValue 成对；任一失败整体拒绝并返回具体原因；
4. **编码生成**（沿用旧文档评审结论，防唯一索引冲突）：codeColumn 有值取列值；否则 `"{classLocalName 小写}-{biz_key}"`；biz_key 空 → 跳过该行并记 skipReason；**禁止把 name 列配成 codeColumn**（生效校验链拒绝同名配置并提示）；
5. **身份一致性**：`ont_objects` 上 `(class_id, biz_table, biz_key)` 部分唯一——同一业务记录至多一个本体对象；upsert 语义：存在则按 conflictStrategy 更新/报告，**冲突不另建**；
6. **值转换**：PG dataType → xsdType 按兼容组（附录A）转换后存 `value_json`；不兼容组转换失败 → 该值不落库 + issuesCount++（行继续）；xsdType 为空/any 组宽松放行（原文存 value_json）；
7. **关系解析**：对象属性绑定的 bizColumn 值视为目标类业务表的主键值 → 经目标类的**生效绑定**定位目标对象（按 biz_table+biz_key 反查）；目标类无生效绑定或对象不存在 → resolved=false → 按 missingTargetPolicy 处理；
8. **增量**：`WHERE updateTimeColumn > watermark`；扫描成功后 watermark=本次扫描行最大值；supportsIncremental=0 的表强制全量（提示）；
9. **全量孤儿检测**：以**不带状态过滤**的 key 全集对比已物化对象——缺失 → state=3 + issue；存在但状态列非在用值 → state=2；`includeDisabled=1` 时停用行也参与物化（state=2）；
10. **行级容错**：同步按行独立提交（单行失败 failed++ 不断整体）；「部分成功」是正常业务结果；dry-run 完全只读（零写入零日志）；
11. **归档传导**：绑定创建/编辑/生效/触发同步均先过 `AssertProjectWritable`。

## 三、数据库设计

### 3.1 迁移文件

```
server/migrations/
├── 000009_create_ont_ext_binding.up.sql     # 注册表3 + 绑定3 + 日志1 + 对象落地3，共10张表
└── 000009_create_ont_ext_binding.down.sql   # 按依赖逆序 DROP（对象 → 日志 → 绑定属性/子表 → 绑定 → 表 → 模块）
```

> 本功能状态枚举（bindingStatus/syncMode/detailKind 等）参考前端均为**本地 options**（非系统字典），不种字典。

### 3.2 建表 DDL（up.sql）

```sql
-- ── 注册表域 ──────────────────────────────────────────────
CREATE TABLE IF NOT EXISTS ont_ext_modules (
    id           bigserial     PRIMARY KEY,
    module_code  varchar(64)   NOT NULL,
    name         varchar(128)  NOT NULL,
    service_name varchar(128)  NOT NULL DEFAULT '',
    description  varchar(512)  NOT NULL DEFAULT '',
    status       smallint      NOT NULL DEFAULT 0,          -- 0启用/1停用
    sort_order   int           NOT NULL DEFAULT 0,
    created_by   varchar(64)   NOT NULL DEFAULT '',
    updated_by   varchar(64)   NOT NULL DEFAULT '',
    created_at   timestamptz   NOT NULL DEFAULT now(),
    updated_at   timestamptz   NOT NULL DEFAULT now(),
    deleted_at   timestamptz
);
COMMENT ON TABLE ont_ext_modules IS '外部模块注册（业务表逻辑分组）';
CREATE UNIQUE INDEX IF NOT EXISTS uk_ont_ext_module_code
    ON ont_ext_modules (module_code) WHERE deleted_at IS NULL;

CREATE TABLE IF NOT EXISTS ont_ext_tables (
    id                  bigserial     PRIMARY KEY,
    module_id           bigint        NOT NULL,
    table_name          varchar(128)  NOT NULL,
    display_name        varchar(128)  NOT NULL DEFAULT '',
    pk_column           varchar(128)  NOT NULL DEFAULT 'id',
    pk_type             varchar(64)   NOT NULL DEFAULT '',
    deleted_column      varchar(128)  NOT NULL DEFAULT '',
    update_time_column  varchar(128)  NOT NULL DEFAULT '',
    supports_incremental smallint     NOT NULL DEFAULT 0,
    remark              varchar(512)  NOT NULL DEFAULT '',
    created_by          varchar(64)   NOT NULL DEFAULT '',
    updated_by          varchar(64)   NOT NULL DEFAULT '',
    created_at          timestamptz   NOT NULL DEFAULT now(),
    updated_at          timestamptz   NOT NULL DEFAULT now(),
    deleted_at          timestamptz
);
COMMENT ON TABLE ont_ext_tables IS '外部表注册（物理表全局至多注册一次；deleted/update_time 列注册时探测回填）';
COMMENT ON COLUMN ont_ext_tables.deleted_column IS '业务表软删列（探测：优先deleted_at回退deleted；同步WHERE用）';
COMMENT ON COLUMN ont_ext_tables.update_time_column IS '水位列（探测：优先updated_at回退update_time；增量同步用）';
COMMENT ON COLUMN ont_ext_tables.supports_incremental IS '支持增量 0/1（有水位列即1）';

CREATE UNIQUE INDEX IF NOT EXISTS uk_ont_ext_table_name
    ON ont_ext_tables (table_name) WHERE deleted_at IS NULL;
CREATE INDEX IF NOT EXISTS idx_ont_ext_table_module
    ON ont_ext_tables (module_id) WHERE deleted_at IS NULL;

-- ── 绑定域 ────────────────────────────────────────────────
CREATE TABLE IF NOT EXISTS ont_ext_bindings (
    id                    bigserial     PRIMARY KEY,
    project_id            bigint        NOT NULL,
    class_id              bigint        NOT NULL,
    table_id              bigint        NOT NULL,
    key_column            varchar(128)  NOT NULL DEFAULT 'id',
    code_column           varchar(128)  NOT NULL DEFAULT '',
    name_column           varchar(128)  NOT NULL DEFAULT '',
    parent_column         varchar(128)  NOT NULL DEFAULT '',
    status_column         varchar(128)  NOT NULL DEFAULT '',
    status_active_value   varchar(64)   NOT NULL DEFAULT '',
    sync_mode             smallint      NOT NULL DEFAULT 1,  -- 1手动/2定时+手动(调度预留)
    sync_order            int           NOT NULL DEFAULT 100,
    include_disabled      smallint      NOT NULL DEFAULT 0,
    conflict_strategy     smallint      NOT NULL DEFAULT 2,  -- 1仅报告/2业务表覆盖
    missing_target_policy smallint      NOT NULL DEFAULT 1,  -- 1跳过记issue/2整行失败
    binding_status        smallint      NOT NULL DEFAULT 0,  -- 0草稿/1生效/2停用
    telemetry_enabled     smallint      NOT NULL DEFAULT 0,  -- 遥测直读（预留）
    watermark             timestamptz,
    last_sync_time        timestamptz,
    last_sync_summary     varchar(512)  NOT NULL DEFAULT '',
    remark                varchar(512)  NOT NULL DEFAULT '',
    created_by            varchar(64)   NOT NULL DEFAULT '',
    updated_by            varchar(64)   NOT NULL DEFAULT '',
    created_at            timestamptz   NOT NULL DEFAULT now(),
    updated_at            timestamptz   NOT NULL DEFAULT now(),
    deleted_at            timestamptz
);
COMMENT ON TABLE ont_ext_bindings IS '类绑定配置（类↔主表；一个类至多一条生效绑定）';

CREATE INDEX IF NOT EXISTS idx_ont_ext_binding_project
    ON ont_ext_bindings (project_id) WHERE deleted_at IS NULL;
CREATE INDEX IF NOT EXISTS idx_ont_ext_binding_class
    ON ont_ext_bindings (class_id) WHERE deleted_at IS NULL;
CREATE INDEX IF NOT EXISTS idx_ont_ext_binding_status
    ON ont_ext_bindings (binding_status) WHERE deleted_at IS NULL;
CREATE UNIQUE INDEX IF NOT EXISTS uk_ont_ext_binding_class_active
    ON ont_ext_bindings (class_id) WHERE binding_status = 1 AND deleted_at IS NULL;

CREATE TABLE IF NOT EXISTS ont_ext_binding_details (
    id                 bigserial     PRIMARY KEY,
    binding_id         bigint        NOT NULL,
    table_id           bigint        NOT NULL,
    detail_kind        smallint      NOT NULL DEFAULT 1,     -- 1宽表一对一/2窄表EAV
    join_column        varchar(128)  NOT NULL DEFAULT '',
    identifier_column  varchar(128)  NOT NULL DEFAULT '',    -- 窄表：属性标识列
    value_column       varchar(128)  NOT NULL DEFAULT '',    -- 窄表：值列（宽表可空）
    ts_column          varchar(128)  NOT NULL DEFAULT '',
    sort_order         int           NOT NULL DEFAULT 0,
    remark             varchar(512)  NOT NULL DEFAULT '',
    created_at         timestamptz   NOT NULL DEFAULT now(),
    updated_at         timestamptz   NOT NULL DEFAULT now(),
    deleted_at         timestamptz
);
COMMENT ON TABLE ont_ext_binding_details IS '子表绑定（宽表=一对一扩展行；窄表=EAV一行一属性）';
CREATE INDEX IF NOT EXISTS idx_ont_ext_bd_binding
    ON ont_ext_binding_details (binding_id) WHERE deleted_at IS NULL;

CREATE TABLE IF NOT EXISTS ont_ext_binding_properties (
    id                 bigserial     PRIMARY KEY,
    binding_id         bigint        NOT NULL,
    binding_type       smallint      NOT NULL DEFAULT 1,     -- 1数据属性/2对象属性
    property_id        bigint        NOT NULL,               -- → ont_model_datatype/object_properties.id
    detail_binding_id  bigint,                               -- 值来源子表（NULL=主表）
    biz_column         varchar(128)  NOT NULL DEFAULT '',    -- 主/宽表=列名；窄表=identifier匹配值
    value_converter    smallint      NOT NULL DEFAULT 0,     -- 预留：值转换器
    const_value        varchar(512)  NOT NULL DEFAULT '',    -- 预留：常量值
    enabled            smallint      NOT NULL DEFAULT 1,
    sort_order         int           NOT NULL DEFAULT 0,
    remark             varchar(512)  NOT NULL DEFAULT '',
    created_at         timestamptz   NOT NULL DEFAULT now(),
    updated_at         timestamptz   NOT NULL DEFAULT now(),
    deleted_at         timestamptz
);
COMMENT ON TABLE ont_ext_binding_properties IS '属性绑定（类属性↔业务列；窄表来源 biz_column 存 identifier 匹配值）';
CREATE INDEX IF NOT EXISTS idx_ont_ext_bp_binding
    ON ont_ext_binding_properties (binding_id) WHERE deleted_at IS NULL;
CREATE INDEX IF NOT EXISTS idx_ont_ext_bp_property
    ON ont_ext_binding_properties (property_id) WHERE deleted_at IS NULL;

-- ── 同步日志 ──────────────────────────────────────────────
CREATE TABLE IF NOT EXISTS ont_ext_sync_logs (
    id            bigserial     PRIMARY KEY,
    binding_id    bigint        NOT NULL,
    class_id      bigint        NOT NULL,
    trigger_type  smallint      NOT NULL DEFAULT 2,          -- 1反向(预留)/2手动/3定时(预留)/4试运行(预留)
    sync_scope    smallint      NOT NULL DEFAULT 1,          -- 1全量/2增量
    total_rows    int           NOT NULL DEFAULT 0,
    created       int           NOT NULL DEFAULT 0,
    updated       int           NOT NULL DEFAULT 0,
    skipped       int           NOT NULL DEFAULT 0,
    failed        int           NOT NULL DEFAULT 0,
    issues_count  int           NOT NULL DEFAULT 0,
    status        smallint      NOT NULL DEFAULT 1,          -- 1成功/2部分失败/3失败
    duration_ms   int           NOT NULL DEFAULT 0,
    summary       varchar(1000) NOT NULL DEFAULT '',
    skip_reasons  text          NOT NULL DEFAULT '',         -- JSON数组
    start_time    timestamptz   NOT NULL DEFAULT now(),
    end_time      timestamptz
);
COMMENT ON TABLE ont_ext_sync_logs IS '外部同步日志（一次触发一条；试运行不记录）';
CREATE INDEX IF NOT EXISTS idx_ont_ext_log_binding
    ON ont_ext_sync_logs (binding_id) WHERE deleted_at IS NULL;
CREATE INDEX IF NOT EXISTS idx_ont_ext_log_class
    ON ont_ext_sync_logs (class_id) WHERE deleted_at IS NULL;

-- ── 对象落地（同步写目标；完整对象管理为后续需求） ──────────
CREATE TABLE IF NOT EXISTS ont_objects (
    id             bigserial     PRIMARY KEY,
    project_id     bigint        NOT NULL,
    class_id       bigint        NOT NULL,
    object_code    varchar(128)  NOT NULL,
    object_name    varchar(255)  NOT NULL DEFAULT '',
    parent_id      bigint,                                   -- 树形类父对象（可空）
    state          smallint      NOT NULL DEFAULT 1,         -- 1在用/2停用/3失联(孤儿)
    source_type    smallint      NOT NULL DEFAULT 2,         -- 1本体系(预留)/2业务同步
    biz_table      varchar(128)  NOT NULL DEFAULT '',
    biz_key        varchar(128)  NOT NULL DEFAULT '',
    last_sync_time timestamptz,
    created_by     varchar(64)   NOT NULL DEFAULT '',
    updated_by     varchar(64)   NOT NULL DEFAULT '',
    created_at     timestamptz   NOT NULL DEFAULT now(),
    updated_at     timestamptz   NOT NULL DEFAULT now(),
    deleted_at     timestamptz
);
COMMENT ON TABLE ont_objects IS '本体对象个体（ABox；本期由同步物化，对象管理页后续交付）';
COMMENT ON COLUMN ont_objects.state IS '1在用/2停用(状态列非在用值)/3失联(全量孤儿)';

CREATE UNIQUE INDEX IF NOT EXISTS uk_ont_objects_code
    ON ont_objects (project_id, object_code) WHERE deleted_at IS NULL;
CREATE UNIQUE INDEX IF NOT EXISTS uk_ont_objects_biz
    ON ont_objects (class_id, biz_table, biz_key)
    WHERE deleted_at IS NULL AND biz_table <> '';

CREATE TABLE IF NOT EXISTS ont_object_attr_values (
    id           bigserial     PRIMARY KEY,
    object_id    bigint        NOT NULL,
    property_id  bigint        NOT NULL,                      -- → ont_model_datatype_properties.id
    value_json   text          NOT NULL DEFAULT '',            -- 按 xsd 兼容组转换后的 JSON 标量
    created_at   timestamptz   NOT NULL DEFAULT now(),
    updated_at   timestamptz   NOT NULL DEFAULT now(),
    deleted_at   timestamptz
);
COMMENT ON TABLE ont_object_attr_values IS '对象数据属性值（EAV；对象属性值走 ont_object_relations）';
CREATE UNIQUE INDEX IF NOT EXISTS uk_ont_oav
    ON ont_object_attr_values (object_id, property_id) WHERE deleted_at IS NULL;

CREATE TABLE IF NOT EXISTS ont_object_relations (
    id                  bigserial   PRIMARY KEY,
    object_id           bigint      NOT NULL,
    object_property_id  bigint      NOT NULL,                 -- → ont_model_object_properties.id
    target_object_id    bigint      NOT NULL,
    created_at          timestamptz NOT NULL DEFAULT now(),
    updated_at          timestamptz NOT NULL DEFAULT now(),
    deleted_at          timestamptz
);
COMMENT ON TABLE ont_object_relations IS '对象关系（对象属性实例化；来源业务表外键列解析）';
CREATE UNIQUE INDEX IF NOT EXISTS uk_ont_or
    ON ont_object_relations (object_id, object_property_id, target_object_id) WHERE deleted_at IS NULL;
CREATE INDEX IF NOT EXISTS idx_ont_or_target
    ON ont_object_relations (target_object_id) WHERE deleted_at IS NULL;
```

### 4.2 Service 层关键逻辑

```go

// GetExtModuleList：全量 + tableCount（ext_tables 按模块 COUNT 子查询/分组聚合），Order sort_order,id

//   + pg_description 取表注释 + LEFT JOIN 本注册表标注 registered

// GetExtBinding：主表 + 双子表清单（编辑回填）
// GetExtBindingList：分页 + 富化（projectCode/class 信息/tableName/行数计数）
// ChangeExtBindingStatus(id, status)：→1 走生效校验链（§二.3，逐条拼接失败原因）；→2 直接置停用
// DeleteExtBinding：存在校验 → 有同步日志保留（日志不级联，仅软删绑定+双子表）

// ── ExtSyncService ──
// DryRunExtBinding(bindingId, limit)：绑定存在（任意状态可试运行，生效前预演主场景）→
```

### 4.3 ExtDynamicQueryService（动态读业务表，安全关键）

```go
// 三方法（对标旧文档 BizTableQueryService，双层防注入）：
// AssertTableValid(tableName) (cols map[string]string, err)：
//     information_schema 白名单命中才放行（未注册的物理表拒绝动态查询）
// QuoteIdent(s) string：双引号包裹 + 转义内部双引号（表名/列名统一过此函数）
// EscapeLike(s) string：转义 % _ \（ILIKE 通配符注入）
// SelectRows(cfg, where...)：SELECT 显式列清单 FROM "表" WHERE 软删条件 [AND ...]
//     ORDER BY 主键 LIMIT ? OFFSET ?——值/分页一律占位符参数化（global.GVA_DB.Raw）
// 软删条件按 deletedColumn 类型分支：timestamptz → "col" IS NULL；数值/bit → "col" = 0
```

**规则**：动态 SQL 的标识符只能来自**已注册表 + 绑定配置**（先过 information_schema 白名单校验），值与 LIMIT/OFFSET 一律 `?` 参数化；禁止字符串拼接任何用户输入进 SQL 文本。

## 五、同步引擎设计

### 5.1 主流程（TriggerExtSync）

```
前置：绑定存在且 bindingStatus=1 → AssertProjectWritable → 加载 表配置/子表绑定/启用属性绑定
     → AssertTableValid（主表+全部子表白名单校验）
互斥：SELECT * FROM ont_ext_bindings WHERE id=? FOR UPDATE（同步期间阻塞同绑定并发触发，事务结束释放）
取数：scope=2 → WHERE 水位列 > watermark（supportsIncremental=0 强制按全量并 warning）
     scope=1 → 全表（软删条件 + [status 过滤：includeDisabled=0 且 statusColumn 配置时排除非在用行]）
     ORDER BY 主键；宽表子表按 joinColumn IN (本批 keys) 二次取数 → 内存 map 按 join 值归组
     窄表子表同理取数 → 按 (join值, identifier值) 建索引供属性取值
行循环（每行独立小事务提交）：
  ① biz_key 空 → skipped++（skipReasons「主键列值为空」）
  ② 编码 = codeColumn列值（空则 "{classLocalName小写}-{biz_key}"）；同名对象编码已存在且非本 biz_key → skipped++（「对象编码冲突：xxx」）
  ③ 查 ont_objects(class_id, biz_table, biz_key)：
     不存在 → 新建（object_code/object_name=name列值兜底编码/state=按状态列判定 1/2/source_type=2）→ created++
     存在 → conflictStrategy=2 → 覆盖 name/state/parent（值变才写，updated++）；=1 → diff 计 issues++（仅报告）
  ④ 树形父解析：parentColumn 值 → 同绑定 (biz_table, parent_key) 反查对象；未命中 → missingTargetPolicy（见⑦）
  ⑤ 数据属性值：逐条启用绑定取原始值（主表列 / 宽表子表列 / 窄表 identifier 匹配）→ 兼容组转换（附录A）
     成功 → upsert ont_object_attr_values(object_id, property_id, value_json)
     失败 → 该值跳过 + issues++（「属性X列Y类型不兼容」）
  ⑥ 关系解析：对象属性绑定 bizColumn 值 → 目标类（range_class_id）生效绑定的 (biz_table, biz_key) 反查对象
     命中 → upsert ont_object_relations；未命中 → missingTargetPolicy（见⑦）；dry-run 时只标 resolved=false
  ⑦ missingTargetPolicy：1=跳过该父/关系并 issues++（行继续）；2=failed++（整行失败，本行不落库/不更新）
收尾（scope=1）：孤儿检测——不带状态过滤取 key 全集 → 已物化对象差集 → state=3 + issues++（「孤儿：biz_key=x 业务行不存在」）
收尾（scope=2）：watermark = 本批最大水位列值（空批不回退水位）
落日志：一条 ont_ext_sync_logs（计数/耗时/summary「创建x/更新y/跳过z/失败w/问题n」/skipReasons JSON）
       回写绑定 last_sync_time/last_sync_summary
status 判定：failed>0 且 failed=totalRows → 3；failed>0 或 issues>0 → 2；否则 1
```

### 5.2 dry-run 与同步的复用关系

DryRun 复用同一套「配置加载 → 动态取数（LIMIT）→ 行组装」代码路径，差异仅在**写侧短路**（不 upsert、不计 created/updated、不落日志、不推进水位），并额外产出 warnings（配置类提示在取数前静态生成）。实现建议：行组装函数签名 `buildRow(row, cfg) (DryRunRow, applyFns)`，dry-run 只取 DryRunRow，同步执行 applyFns。

### 5.3 性能约定

- 主表取数按批分页（每批 500 行）流式处理，避免大表一次性载入；
- 子表/已物化对象反查一律按批 IN（禁止逐行 N+1）；
- 单表 ≤10 万行全量同步目标 P95 < 60s（行级小事务 + 索引命中）；更大表建议增量。

## 十、风险与注意事项

| # | 风险/注意 | 应对 |
|---|---|---|
| 1 | **动态 SQL 注入**（本功能最大风险面） | §4.3 三重防线：information_schema 白名单 → QuoteIdent 双引号转义 → 值/LIMIT 占位符 + EscapeLike；代码评审必须逐条核对无字符串拼接 |
| 2 | **业务表误写** | 动态查询层**只读**（仅 SELECT）；引擎对业务表零写操作（v1 单向）；代码层禁用 Exec 于动态标识符路径 |
| 3 | **同步互斥** | 绑定行 `FOR UPDATE` 作为同进程互斥；多实例部署需升级为 PG advisory lock 或分布式锁（演进项） |
| 4 | **大表全量耗时** | 分批流式 + 行级小事务；引导用增量；同步中不阻塞其他绑定 |
| 5 | **schema 漂移** | 业务表加列无影响；删列在生效校验链/同步 AssertTableValid 即时暴露（报「列不存在」），不会静默错数据 |
| 6 | **对象域边界** | `ont_objects` 三表本期仅同步写入（无手工入口），对象管理页后续交付时复用该表组，避免两套对象存储 |
| 7 | **valueConverter/constValue/telemetry 字段** | 预留列本期不实现交互（前端不渲染或禁用），防止契约漂移 |
| 8 | **日志膨胀** | syncReasons/summary 定长截断；日志保留策略（定期清理）交运维，本期不自动清理 |
| 9 | **宽窄表混用复杂度** | 一个绑定的多条子表绑定可混合宽窄表，但**单条属性绑定的值来源**只能指向一张子表；前端下拉已按 detailKind 过滤来源选项 |
| 10 | **迁移版本冲突** | 实施前核对 `server/migrations/` 最大版本号，000009 被占用则顺延并同步 README 规划 |

## 附录A xsd ↔ PG 类型兼容组

属性绑定列下拉过滤与值转换共用（`xsdGroup(xsd)` 归组后比对 `COMPAT_MAP`）：

| xsd 组 | 兼容 PG dataType | 转换目标 |
|---|---|---|
| string | character varying, character, text, jsonb, uuid | JSON 字符串 |
| integer | smallint, integer, bigint | JSON 数值 |
| decimal | numeric, real, double precision, money | JSON 数值 |
| boolean | boolean, smallint | JSON 布尔（smallint 按 0/1） |
| datetime | timestamp without time zone, timestamp with time zone, date | JSON 字符串（RFC3339） |
| any（xsdType 空/未知） | 全部放行 | 原文入 value_json |

不兼容组合：同步中该值不落库、issues++；dry-run 中标 `converted=false`。对象属性（外键解析）不参与类型过滤。
