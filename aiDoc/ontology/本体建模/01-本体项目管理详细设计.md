## 一、功能概述

### 1.1 功能定位

本体项目是建模域的**顶层容器**：一个项目 = 一套独立本体（消防设备本体、空间本体……）。项目持有三样全局资产：

1. **命名空间基址 namespaceBase**——本项目所有类 / 属性 IRI 的生成前缀（`classIri = namespaceBase + localName`）；
2. **IRI 前缀注册表**——序列化（Turtle/OWL XML）时 `@prefix` 声明的来源，含一个项目级默认前缀；
3. **序列化策略配置**——默认格式（TTL/OWL_XML）与属性组织方案（方案 B 独立副本 / 方案 A 预留禁用）。

02 类建模、03 外部模块关联中的所有写操作都要先过「项目存在且未归档」校验。

### 1.2 功能范围

**含**：

1. 项目 CRUD：分页查询（keyword + status）、详情、创建、更新、删除；
2. 项目编码唯一校验（预查重接口 + DB 部分唯一索引兜底）；
3. 项目状态机：`draft → active → archived` 单向流转，**archived 只读**（编辑/删除/前缀维护全部拒绝）；
4. 前缀管理（项目维度子资源）：列表 + 创建 + 更新 + 删除，NCName 校验、同项目唯一、默认前缀唯一；
5. 项目全量下拉（`getModelProjectAll`，供 02 类建模搜索区、03 绑定表单选项目用）；
6. 序列化策略配置项落库（方案 A v1 禁用，仅存值防御）。

**不含**：类实体（02）、属性/层级（02 附带）、序列化引擎（后续需求）、画布（后续需求）。

### 1.3 与参考设计的差异裁定（以前端实现为准）

| # | 芋道 DD7 设计 | 前端实现（**采用**） | 裁定说明 |

## 二、术语与业务规则

| 术语 | 含义 |
|---|---|
| projectCode | 项目编码（全局唯一，如 `fire-equipment`），亦作为类层级回推镜像的 treeRoot 候选 |
| namespaceBase | IRI 命名空间基址（如 `http://example.com/onto/fire/`）；结尾 `/` 或 `#` 直接拼接 localName，否则补 `/` |
| prefix | Turtle `@prefix` 前缀名，须满足 NCName 语义正则 `^[A-Za-z_][A-Za-z0-9_.-]*$`（如 ex/qudt/brick） |
| 默认前缀 | `isDefault=1` 的前缀，序列化时省略前缀名直接写 IRI；**同项目至多一个** |
| defaultFormat | 默认序列化格式：`TTL`（Turtle）/ `OWL_XML` |
| serializationStrategy | 方案 B=带前缀独立副本（每类独立属性定义，默认）；方案 A=共享属性 + 多 domain（**v1 禁用**，仅预留存值） |
| status | 项目状态：`draft` 草稿 / `active` 活跃 / `archived` 归档（只读） |

**核心业务规则**：

1. **状态机单向**：draft → active → archived；不允许回退（active→draft、archived→active 均拒绝）。归档项目对所有写操作只读（更新、删除、前缀增删改）；
2. **projectCode 全局唯一**：Service 预查重（编辑排除自身）+ 部分唯一索引兜底；
3. **方案 A 禁用**：创建/更新传入 `serializationStrategy='A'` 时业务报错「方案A暂未开放」；
4. **创建默认值**：strategy 空 → `B`；format 空 → `TTL`；status 空 → `draft`（后端兜底，前端表单同默认值）；
5. **前缀规则**：同项目 prefix 唯一（预查重 + 索引兜底）；设 `isDefault=1` 时项目内不得已存在其他默认前缀；取消默认（改 0）允许；
6. **删除级联校验**：项目下存在类（`ont_model_classes`）→ 拒绝删除「项目下存在本体类，无法删除」（02 落地后生效；本期先埋校验点，类数为 0 直通）；
7. **archived 校验下沉**：02/03 的类、属性、绑定写操作均需回查所属项目状态（提供 `AssertProjectWritable(projectId)` 公共校验方法，放本项目 Service，供跨域复用）。

```sql
-- 本体项目（建模域顶层容器）
CREATE TABLE IF NOT EXISTS ont_model_projects (
    id                     bigserial     PRIMARY KEY,
    project_code           varchar(64)   NOT NULL,
    name                   varchar(128)  NOT NULL,
    description            varchar(512)  NOT NULL DEFAULT '',
    namespace_base         varchar(255)  NOT NULL,
    default_format         varchar(16)   NOT NULL DEFAULT 'TTL',
    serialization_strategy varchar(8)    NOT NULL DEFAULT 'B',
    status                 varchar(16)   NOT NULL DEFAULT 'draft',
    created_by             varchar(64)   NOT NULL DEFAULT '',
    updated_by             varchar(64)   NOT NULL DEFAULT '',
    created_at             timestamptz   NOT NULL DEFAULT now(),
    updated_at             timestamptz   NOT NULL DEFAULT now(),
    deleted_at             timestamptz
);
COMMENT ON TABLE ont_model_projects IS '本体项目（建模域顶层容器：命名空间/前缀/序列化策略）';
COMMENT ON COLUMN ont_model_projects.project_code IS '项目编码（全局唯一，如 fire-equipment）';
COMMENT ON COLUMN ont_model_projects.name IS '项目名称';
COMMENT ON COLUMN ont_model_projects.description IS '描述';
COMMENT ON COLUMN ont_model_projects.namespace_base IS 'IRI命名空间基址（classIri = namespace_base + localName）';
COMMENT ON COLUMN ont_model_projects.default_format IS '默认序列化格式 TTL/OWL_XML';
COMMENT ON COLUMN ont_model_projects.serialization_strategy IS '序列化策略 B=带前缀独立副本(默认) A=共享属性+多domain(预留禁用)';
COMMENT ON COLUMN ont_model_projects.status IS '项目状态 draft草稿/active活跃/archived归档(只读)';

CREATE UNIQUE INDEX IF NOT EXISTS uk_ont_model_project_code
    ON ont_model_projects (project_code) WHERE deleted_at IS NULL;
CREATE INDEX IF NOT EXISTS idx_ont_model_project_status
    ON ont_model_projects (status) WHERE deleted_at IS NULL;

-- IRI 前缀注册（项目级）
CREATE TABLE IF NOT EXISTS ont_model_prefixes (
    id          bigserial     PRIMARY KEY,
    project_id  bigint        NOT NULL,
    prefix      varchar(64)   NOT NULL,
    namespace   varchar(255)  NOT NULL,
    is_default  smallint      NOT NULL DEFAULT 0,
    created_by  varchar(64)   NOT NULL DEFAULT '',
    updated_by  varchar(64)   NOT NULL DEFAULT '',
    created_at  timestamptz   NOT NULL DEFAULT now(),
    updated_at  timestamptz   NOT NULL DEFAULT now(),
    deleted_at  timestamptz
);
COMMENT ON TABLE ont_model_prefixes IS '本体项目 IRI 前缀注册（序列化 @prefix 来源）';
COMMENT ON COLUMN ont_model_prefixes.project_id IS '所属项目ID → ont_model_projects.id';
COMMENT ON COLUMN ont_model_prefixes.prefix IS '前缀名（NCName，如 ex/qudt/fire）';
COMMENT ON COLUMN ont_model_prefixes.namespace IS '命名空间 URI';
COMMENT ON COLUMN ont_model_prefixes.is_default IS '是否项目默认前缀 0/1（同项目至多一个1）';

CREATE UNIQUE INDEX IF NOT EXISTS uk_ont_model_prefix
    ON ont_model_prefixes (project_id, prefix) WHERE deleted_at IS NULL;
CREATE INDEX IF NOT EXISTS idx_ont_model_prefix_project
    ON ont_model_prefixes (project_id) WHERE deleted_at IS NULL;
```

### 4.2 Service 层关键逻辑

```go
type ModelProjectService struct{}

// CreateModelProject：projectCode 查重 → 默认值兜底(TTL/B/draft) → strategy=='A' 拒绝 → 填 CreatedBy/UpdatedBy → Create
// UpdateModelProject：存在校验 → archived 拒绝 → 状态机校验(不回退) → projectCode 查重排除自身 → strategy=='A' 拒绝 → Updates(map)
// DeleteModelProject：存在校验 → archived 拒绝 → 类计数>0 拒绝 → 软删（前缀随项目语义废弃，不做级联硬删）
// FindModelProject / GetModelProjectList（keyword LIKE project_code/name + status 等值，Order id DESC 分页）
// GetModelProjectAll：全量（Order id ASC），下拉数据源
// CheckModelProjectCode(projectCode, excludeId) bool：查重
// AssertProjectWritable(projectId) error：存在 + status != 'archived'（02/03 复用）

type ModelPrefixService struct{}

// GetModelPrefixList(projectId)：Order is_default DESC, id ASC
// CreateModelPrefix：项目存在+未归档 → NCName 正则 → 同项目 prefix 查重 → isDefault=1 时项目内不得已有默认 → Create
// UpdateModelPrefix：存在+归属校验 → 同上校验（查重排除自身）→ Updates
// DeleteModelPrefix：存在+归属校验 → 项目未归档 → 软删
```

**状态机校验**：更新时若 `old.Status == "archived"` 拒绝；若 body 传入的 status 与 old 不同，仅允许 `draft→active`、`active→archived` 两个方向。

### 4.3 归档只读的传导

`AssertProjectWritable` 是建模域公共校验（02 类/属性/层级、03 绑定/同步的写入口都调用），错误文案：「项目已归档，只读」。

## 九、风险与注意事项

| # | 风险/注意 | 应对 |
|---|---|---|
| 1 | **目录标题变更影响存量环境** | 种子用幂等 UPDATE 只改 title 不动 name/path，路由与权限不受影响；若运维侧自定义过菜单名，UPDATE 加 `WHERE name='ontology' AND parent_id=0` 收窄 |
| 2 | **namespaceBase 拼接歧义** | 结尾非 `/`/`#` 时统一补 `/`（02 IRI 生成复用同一工具函数，双侧不可各自实现） |
| 3 | **默认前缀竞态** | 「设默认」为读-改-写，并发下可能双默认；Service 内对设默认操作加项目级串行（同事务 `SELECT ... FOR UPDATE` 项目行）兜底 |
| 4 | **删除项目残留前缀** | 项目软删后前缀成为孤儿数据（无查询入口）；本期不级联（保留恢复可能），down 迁移与运维清理脚本知悉即可 |
| 5 | **策略/格式枚举漂移** | status `oneof` 硬校验三值；format/strategy 扩展需同步字典种子 + oneof + 前端 options 三处 |
| 6 | **迁移版本冲突** | 实施前核对 `server/migrations/` 最大版本号，若 000007 已被占用顺延并同步 README 版本规划 |
