## 一、功能概述

### 1.1 功能定位

本体类建模是建模域的核心：在项目容器内创建 `owl:Class`，两种建模方式——

1. **基于分类模板实例化**（推荐）：从治理域分类模板树选模板 → 预览将挂载的属性清单（含祖先继承链）→ 确认后**复制字段值**为类属性，并在类上留下模板溯源（templateCode/classificationCode + 外观继承 icon/color）；
2. **空白创建**：手建类，属性后续在类详情中逐个添加或从属性模板库批量挂载。

类的属性维护**全部内嵌在类详情抽屉**中（数据属性/对象属性两个 Tab），独立的属性查询页与类层级编辑页不在本期范围（见 §1.2）。

### 1.2 功能范围

**含**：

1. 类 CRUD：分页（projectId + keyword + hasTemplate 三态）、详情聚合（属性 + 直接父子类）、创建、更新（编辑白名单）、删除（引用守卫）；
2. IRI 生成：`classIri = namespaceBase + localName`，同项目唯一（预查重 + 索引兜底），localName 创建后不可改；
3. 模板实例化：`instantiate`（单事务复制字段值）+ `instantiate-preview`（继承视图预览，不落库）；
4. 数据属性 CRUD（owl:DatatypeProperty）：xsdType、单位绑定（仅数值型）、枚举值、基数、标识符、排序；
5. 对象属性 CRUD（owl:ObjectProperty）：domain=所属类、range 可选、基数、反向关系建议 inverseOf；
6. 属性级模板实例化：从属性模板库（治理域供给接口）批量挂载，同类下已存在属性后端跳过；
7. `list-by-project`（03 外部模块关联选类用，过滤 isInstantiable=1 由前端做）。

**不含**：

- 属性独立查询页（参考前端为只读页，后续需求）；
- **subClassOf 建立/删除与镜像回推**（DD9 FR-14 层级编辑 + 补偿任务，后续独立需求）——本期**建表预留** `ont_model_subclassofs`，仅用于：类删除守卫（被子类引用拒绝）+ 类详情「层级」Tab 只读聚合；
- RDF 序列化/解析（DD10）、可视化画布（DD11）、本体对象管理（DD12）。

### 1.3 与参考设计的差异裁定（以前端实现为准）

## 二、术语与业务规则

| 术语 | 含义 |
|---|---|
| classIri / localName | 类 IRI = 项目 namespaceBase + localName；localName 正则 `^[A-Za-z][A-Za-z0-9_-]*$`，**创建后不可修改** |
| templateCode / classificationCode | 类的模板溯源：来源分类模板编码 / 其规范分类编码；空串=空白类 |
| isInstantiable | 类是否会实例化为主数据个体（如设备）；=1 的类才能被 03 外部模块关联绑定 |
| 复制字段值 | 模板实例化语义：把治理域模板的字段**快照复制**为类属性，后续独立编辑、不回写模板（区别于引用） |
| 方案 B 属性 IRI | `{namespaceBase}{classLocalName}_{propLocalName}`（每类独立属性定义，序列化消费；手建与实例化统一） |
| xsdType | 数据属性值域：xsd:string / xsd:integer / xsd:decimal / xsd:boolean / xsd:datetime |
| unitRef | 数据属性单位（QUDT IRI）；**仅 xsdType ∈ {xsd:integer, xsd:decimal} 可绑定** |
| 基数 | minCardinality 默认 0 / maxCardinality 默认 -1（无限制，前端显示 n） |
| isIdentifier | 数据属性是否标识符（序列化输出 `ont:isIdentifier`） |
| domain / range | 对象属性的定义域（=所属类，自动填充）/ 值域（目标类，可空） |
| inverseOf | 反向对象属性互指（owl:inverseOf） |

**核心业务规则**：

1. **IRI 生成与唯一**：`buildClassIri(namespaceBase, localName)`——结尾 `/` 或 `#` 直拼，否则补 `/`；同项目 classIri 唯一（localName 预查重 + 部分唯一索引兜底）；
2. **编辑白名单**：仅 label/labelCn/description/icon/color/sortOrder/isInstantiable 可改；classIri/localName/projectId/溯源字段不可改（Update 用 map 显式列白名单）；
3. **删除守卫**（守卫式非级联）：类被 subClassOf 引用（作为 parent）→ 拒绝；类下有数据属性（class_id）或对象属性（domain_class_id 或 range_class_id）→ 拒绝；项目 archived → 拒绝；
4. **模板实例化**（单事务）：
   - 调治理域 `ClassTemplateService.GetClassTemplateInherited(templateCode)` 取继承视图（properties + icon/color）；properties 为空 → 业务错误「该模板（含继承链）未声明任何属性」；
   - 二次查治理域 `ont_class_templates` 取 classificationCode（继承视图不携带）；
   - 更新类：挂 templateCode/classificationCode，icon/color 空值时用模板外观继承覆盖（已有值保留）；
   - 遍历继承视图 properties，按 propertyTemplateCode 批量查 `ont_property_templates` 取 kind/type/unitRef/values/isIdentifier/label/defaultCardinality（缺失 → 回滚「属性模板不存在: xxx」）；
   - 按 kind 分流插入：datatype → `ont_model_datatype_properties`（基数默认 min=0/max=-1）；object → `ont_model_object_properties` 骨架（range_class_id 留空待补）；
   - **幂等**：同类下 localName（=propertyTemplateCode）已存在的属性跳过，不重复插入；类级 templateCode 重复实例化允许（视为补挂/刷新溯源）；
5. **属性级实例化**：`{projectId, classId, templateCode}` → 复制该属性模板为类属性，同类已存在（按 template_code 或 localName 判定）→ 跳过并计入提示（前端逐条串行调用统计成败）；
6. **单位绑定校验**：unitRef 非空时 xsdType 必须为数值型，否则「仅数值型属性可绑定单位」；
7. **属性编辑白名单**：localName/xsdType 创建后不可改（IRI/值域稳定）；可改 label/unitRef/enumValues/基数/isIdentifier/sortOrder；对象属性可改 range/基数/inverseOf/sortOrder/label；
8. **属性删除守卫**：对象属性被 inverseOf 互指时，删除一侧需清空另一侧引用（同事务）；数据/对象属性删除不做值级联（对象域未建）；
9. **项目归档传导**：类/属性的写操作均先过 01 的 `AssertProjectWritable(projectId)`；
10. **反向关系建议**：`suggestInverse(propertyId)` 返回建议（suggestedLocalName=`belongsTo`、domain/range 对调），前端确认后创建反向属性并双向 `inverseOf` 互指（同事务）。

### 4.2 Service 层关键逻辑

```go
// ── ModelClassService ─────────────────────────────────────────
// CreateModelClass：AssertProjectWritable → localName 正则 → buildClassIri → 同项目 IRI/localName 查重
//   → Create（templateCode 等溯源字段强制空串，只允许 instantiate 写入）
// UpdateModelClass：存在校验 → 归档校验 → Updates(map) 白名单：label/labelCn/description/icon/color/sortOrder/isInstantiable/updatedBy
// DeleteModelClass：存在校验 → 归档校验 → 三重守卫：
//   ① subclassofs.parent_class_id 引用 → 「该类被子类引用，无法删除」
//   ② datatype_properties.class_id 或 object_properties.domain/range_class_id → 「该类下存在属性，无法删除」
//   → 软删
// GetModelClassList：projectId 等值 + keyword LIKE(label/label_cn/local_name)
//   + hasTemplate 三态（"true"→template_code<>'' / "false"→template_code=''）Order sort_order,id 分页
// GetModelClassByProject(projectId)：全量（03 选类用）
// GetModelClassDetail(id)：类 + 属性双清单（Order sort_order,id）+ parentClasses/childClasses（subclassofs 双向 join 类表）
// CheckModelClassLocalName(projectId, localName, excludeId) bool
// buildClassIri(namespaceBase, localName) string   // 结尾 / # 直拼，否则补 /

// ── ClassInstantiationService（单事务 global.GVA_DB.Transaction）──
// InstantiateClass(req {projectId, classId, templateCode})：
//   AssertProjectWritable → 类存在 → 继承视图 = 治理域 ClassTemplateService.GetClassTemplateInherited(templateCode)
//   → properties 空 → 「该模板（含继承链）未声明任何属性」
//   → 二次查 ont_class_templates 取 classificationCode（缺失 → 「分类模板不存在」）
//   → 更新类溯源（templateCode/classificationCode；icon/color 为空时以模板外观覆盖）
//   → 收集 propertyTemplateCodes 一次 IN 查 ont_property_templates（缺失任一 → 回滚「属性模板不存在: xxx」）
//   → 逐条按 kind 分流构造属性（IRI = buildDatatypePropertyIri 方案B；localName = propertyTemplateCode；
//     datatype 带 type/unitRef/values/isIdentifier/label、基数 0/-1；object 骨架 range 留空）
//   → 同类已存在 localName 的属性跳过 → 批量插入
// PreviewInstantiate(projectId, templateCode) *InstantiatePreview：只读组装（继承视图 + 模板批量查富化）

// ── DatatypePropertyService ───────────────────────────────────
// Create：AssertProjectWritable → 所属类存在 → localName 正则 + 同类查重 → validateUnitBinding
//   → IRI=方案B → Create
// Update：白名单 label/unitRef/enumValues/基数/isIdentifier/sortOrder（localName/xsdType 不可改）
// Delete：存在校验 → 归档校验 → 软删
// InstantiateFromTemplate(req)：复制单条属性模板（幂等跳过同类已有）
// validateUnitBinding(xsdType, unitRef)：unitRef 非空 && xsdType ∉ {xsd:integer, xsd:decimal} → 错误

// ── ObjectPropertyService ─────────────────────────────────────
// Create：domainClassId=所属类自动填充 → rangeClassId 可空（非空校验同项目存在）→ 同类 localName 查重
// Update：白名单 label/rangeClassId/基数/inverseOf/sortOrder
// Delete：存在校验 → inverse_of 互指清理（对方置 NULL，同事务）→ 软删
// SuggestInverse(propertyId)：返回 {suggestedLocalName:"belongsTo", suggestedLabel:对方类名+"归属",
//   suggestedDomainClassId: range, suggestedRangeClassId: domain}（range 为空时提示先补 range）
```

**治理域边界（R-23 适配）**：建模域只调用治理域 `ClassTemplateService.GetClassTemplateInherited` / `PropertyTemplateService` 的**只读查询**与既有供给接口，不写治理域任何表（`ont_class_hierarchies` 镜像写入属后续层级回推需求，不在本期）。

| 03 依赖 | 03 绑定表单选类 | `getModelClassByProject` 仅返回项目内类，前端过滤 isInstantiable=1 |

## 九、风险与注意事项

| # | 风险/注意 | 应对 |
|---|---|---|
| 1 | **治理域模板被删/弃用** | 实例化只做快照，模板删除不影响已建类；预览/实例化时模板缺失报业务错误即可；hasTemplate 过滤只看类上的存量溯源字段 |
| 2 | **实例化事务边界** | 类溯源更新 + 属性批量插入必须在同一 `Transaction`；任一属性模板缺失整体回滚（提示具体缺失编码） |
| 3 | **方案 B IRI 与 localName 冲突** | 属性 localName 同类唯一（查重 + 项目级 IRI 唯一索引双保险）；实例化属性 localName=propertyTemplateCode，与手建属性命名空间一致，先到先得 |
| 4 | **xsdType/unitRef 联动漂移** | 前端显隐 + 后端 validateUnitBinding 双重校验；xsdType 创建后不可改，避免已绑单位失效 |
| 5 | **inverseOf 悬挂** | 删除对象属性同事务清对方互指；软删恢复场景（GVA 软删不恢复）不处理 |
| 6 | **subclassofs 表空置** | 本期无写入入口，删除守卫/详情层级恒为空属预期；后续层级功能上线后自然生效，接口不变 |
| 7 | **isInstantiable 语义** | 该开关是 03 绑定的准入条件；文档与前端 help 文案保持一致解释，避免被理解为「是否生成个体」的执行动作 |
| 8 | **大项目属性量** | 详情聚合/实例化均为索引查询 + 批量 IN；分页列表不 join 属性计数（列无此需求），避免慢查询 |
