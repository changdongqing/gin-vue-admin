## 一、功能概述

### 1.1 功能定位

注释属性注册表集中声明所有 `ont:xxx` 注释属性（如 `icon`、`unitRef`、`templateRef`）：建模侧的序列化器/解析器**遍历注册表驱动读写**注释属性——新增一种注释属性只需在注册表加一行，建模侧自动支持（无需改代码）。这是"数据驱动 schema"的登记中心。

每条声明包含：属性名（localName，唯一）、显示名、值域 XSD 类型（rangeXsd）、作用对象（appliesTo：class/datatypeProperty/objectProperty/individual/all）、描述、排序。

### 1.2 功能范围

**含**：
1. 注册表全栈 CRUD（分页、详情、创建、更新、删除）——**无 builtin 保护**，全部记录可编辑/删除（声明式注册表，治理员可调整内置项的 appliesTo/rangeXsd/描述）；
2. localName 唯一约束（部分唯一索引 + Service 校验）；
3. 创建时间范围查询（列表搜索 RangePicker）；
4. **Excel 导出**（excelize，含 编号/属性名/显示名/值域类型/作用对象/描述 列）；
5. 供给接口 `/ontology/supply/v1/annotationProperties`（全量注册表，建模侧序列化驱动）；
6. 列表展示审计列（创建人/创建时间/更新人/更新时间 → 实体的 CreatedBy/UpdatedAt 等字段）。

**不含**：参考本体（CCO）浏览/导入（贯穿阶段）；注释属性与具体元素实例值的读写（建模侧职责）。

### 1.3 与参考设计的差异裁定（以前端实现为准）

| # | 芋道 M4 设计 | 前端实现（**采用**） | 裁定说明 |
|---|---|---|---|
| 1 | 分页参数仅 appliesTo/keyword | 增加 **createTime 范围查询**（RangePicker） | 本项目落地为 `startTime/endTime` query 参数（前端 RangePicker 值映射） |
| 2 | RespVO 不含操作人 | 前端列表展示 **creator/createTime/updater/updateTime 四审计列** | 实体增加 `CreatedBy/UpdatedBy`（与 01~03 同口径），CreatedAt/UpdatedAt 由 GVA_MODEL 提供 |
| 3 | 无冲突项（表结构/无 builtin 保护/appliesTo 枚举/导出列） | 一致 | — |

## 二、术语与业务规则

| 术语 | 含义 |
|---|---|
| localName | 注释属性名（唯一，如 `icon`、`templateRef`），序列化时拼接为 `ont:{localName}` |
| rangeXsd | 值域 XSD 类型（如 `xsd:string`、`xsd:boolean`、`xsd:anyURI`），约束注释取值类型 |
| appliesTo | 作用对象：`class` 类 / `datatypeProperty` 数据属性 / `objectProperty` 对象属性 / `individual` 个体 / `all` 全部 |
| sort | 排序号，供给与列表展示顺序 |

**核心业务规则**：

1. **无 builtin 保护**：注册表所有记录（含 12 条内置种子）均可编辑/删除——治理员可能需要调整内置声明的 appliesTo/rangeXsd/描述（与 01~03 的 builtin 保护策略**刻意不同**，原因：注释属性是声明式元数据，调整不影响既有数据语义）；
2. **localName 唯一**：全局唯一（部分唯一索引 + Service 校验，编辑排除自身）；
3. **appliesTo 只存储声明，不做强校验**：作用对象约束在**建模侧消费时**执行（如 `isIdentifier`（appliesTo=datatypeProperty）不会用于 class）；供给接口原样带出 appliesTo 供建模侧判断；
4. **删除提示**：注释属性被删除后，建模侧序列化将不再输出对应 `ont:xxx`（数据驱动），前端删除确认文案需说明影响；
5. **导出全量**：按当前搜索条件导出全部匹配记录（不受分页限制）。

CREATE TABLE IF NOT EXISTS ont_annotation_properties (
    id          bigserial     PRIMARY KEY,
    local_name  varchar(64)   NOT NULL,
    label       varchar(128)  NOT NULL,
    range_xsd   varchar(64)   NOT NULL DEFAULT '',
    applies_to  varchar(32)   NOT NULL DEFAULT 'all',
    description varchar(512)  NOT NULL DEFAULT '',
    sort        int           NOT NULL DEFAULT 0,
    created_by  varchar(64)   NOT NULL DEFAULT '',
    updated_by  varchar(64)   NOT NULL DEFAULT '',
    created_at  timestamptz   NOT NULL DEFAULT now(),
    updated_at  timestamptz   NOT NULL DEFAULT now(),

COMMENT ON TABLE ont_annotation_properties IS '本体注释属性注册表（ont:xxx 集中声明，建模侧序列化驱动）';
COMMENT ON COLUMN ont_annotation_properties.local_name IS '注释属性名（唯一，如 icon/unitRef）';

COMMENT ON COLUMN ont_annotation_properties.updated_by IS '更新人';

### 4.2 Service 层关键逻辑

```go
type AnnotationPropertyService struct{}

// GetAnnotationPropertyList 分页（keyword 匹配 localName/label；可选时间范围）
func (s *AnnotationPropertyService) GetAnnotationPropertyList(info ontReq.SearchAnnotationProperty) (list []ontology.OntAnnotationProperty, total int64, err error) {
	db := global.GVA_DB.Model(&ontology.OntAnnotationProperty{})
	if info.AppliesTo != "" { db = db.Where("applies_to = ?", info.AppliesTo) }
	if info.Keyword != "" {
		kw := "%" + info.Keyword + "%"
		db = db.Where("local_name LIKE ? OR label LIKE ?", kw, kw)
	}
	if info.StartTime != "" { db = db.Where("created_at >= ?", info.StartTime) }
	if info.EndTime != "" { db = db.Where("created_at <= ?", info.EndTime) }
	if err = db.Count(&total).Error; err != nil { return }
	err = db.Order("sort ASC, id ASC").Limit(info.PageSize).Offset((info.Page - 1) * info.PageSize).Find(&list).Error
	return
}

// GetAnnotationPropertyAll 导出/下拉数据源：同上条件、去分页（Limit -1 语义由调用方控制）
// Create：validateLocalNameUnique(0, localName) → 填 CreatedBy/UpdatedBy → Create
// Update：存在校验 + validateLocalNameUnique(id, localName) → Updates(map)（含 UpdatedBy）
// Delete：存在校验 → 软删（无 builtin 保护）
// GetAnnotationPropertiesForSupply：全量（Order sort,id），供给用
```

> 无 builtin 保护是本服务与 01~03 的**唯一策略差异**，其余范式（唯一校验/errors.New/事务审计）一致。

### 4.3 导出实现（excelize）

`api/v1/ontology/ont_annotation_property.go`：

```go
// ExportAnnotationPropertyExcel 导出注释属性清单
// @Router /ontology/annotationProperty/exportAnnotationPropertyExcel [get]
func (api *OntAnnotationPropertyApi) ExportAnnotationPropertyExcel(c *gin.Context) {
	var info ontReq.SearchAnnotationProperty
	if err := c.ShouldBindQuery(&info); err != nil { response.FailWithMessage(err.Error(), c); return }
	list, _, err := annotationPropertyService.GetAnnotationPropertyAll(info) // 按当前搜索条件全量
	if err != nil { /* FailWithMessage */ return }
	f := excelize.NewFile()
	sheet := "注释属性清单"
	f.SetSheetValue(sheet, "A1", "编号"); f.SetSheetValue(sheet, "B1", "注释属性名")
	f.SetSheetValue(sheet, "C1", "显示名"); f.SetSheetValue(sheet, "D1", "值域类型")
	f.SetSheetValue(sheet, "E1", "作用对象"); f.SetSheetValue(sheet, "F1", "描述")
	for i, item := range list {
		r := i + 2
		f.SetSheetValue(sheet, fmt.Sprintf("A%d", r), item.ID)
		f.SetSheetValue(sheet, fmt.Sprintf("B%d", r), item.LocalName)
		// …C/D/E/F 同构…
	}
	c.Header("Content-Type", "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet")
	c.Header("Content-Disposition", `attachment; filename="annotation_properties.xlsx"`)
	if err := f.Write(c.Writer); err != nil { global.GVA_LOG.Error("导出失败!", zap.Error(err)) }
}
```

> 时间格式化：`item.CreatedAt.Format("2006-01-02 15:04:05")` 如需纳入导出列可自行追加；导出不走 `response.Ok*` 封装（直接写文件流）。

## 五、供给接口设计（FR-5）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/ontology/supply/v1/annotationProperties` | 全量注册表（Order sort,id），字段：localName/label/rangeXsd/appliesTo/description |

- 建模侧序列化器/解析器遍历此接口驱动 `ont:xxx` 读写：新增注释属性只改注册表一处，供给自动返回、建模侧自动支持（AC-4.2）；
- appliesTo 的消费侧校验（AC-4.3）：建模侧据 appliesTo 判断 `isIdentifier`（datatypeProperty）不用于 class；治理侧只存储声明；
- 数量预期 ≤ 数十条，供给不分页；
- 供给路由组无 OperationRecord，casbin 登记「本体供给」组（建模师角色可访问）。

| AC-4.5 唯一 | 重复 localName 新增/编辑 | 业务错误「注释属性名已存在」（唯一索引 + Service 双重） |
| 无 builtin 保护 | 编辑/删除内置 icon 行 | 允许（与 01~03 相反，符合前端实现） |
| 时间范围 | 搜索创建时间区间 | 仅返回区间内记录 |
| 审计列 | 新增/更新后查列表 | createdBy/updatedBy=当前用户，时间自动 |
| 供给权限 | 建模师角色调供给 | 可访问；调治理 create 被拒 |

## 十、风险与注意事项

| # | 风险/注意 | 应对 |
|---|---|---|
| 1 | **删除影响序列化** | 删除注册项后建模侧不再输出对应 ont:xxx；删除确认文案明示；不建议删除 templateRef/unitRef 等链路关键项（可在描述中标注"关键项勿删"） |
| 2 | **导出与分页复用条件** | 导出走 `getAnnotationPropertyAll`（同条件去分页），避免两套条件逻辑漂移 |
| 3 | **blob 下载与统一响应拦截冲突** | `@/utils/request` 拦截器按 `{code,data,msg}` 解析，blob 响应需跳过 code 判断（responseType:'blob' 分支）；实现时核对拦截器行为 |
| 4 | **appliesTo 枚举漂移** | binding `oneof` 硬校验五值；扩展枚举需同步字典种子 + oneof + 前端 options 三处 |
| 5 | **localName 命名规范** | camelCase（与 ont:xxx 拼接后的可读性）；表单 placeholder 引导，不做强正则（兼容存量种子命名如 unitRef） |
| 6 | **排序语义** | sort 相同按 id 升序兜底；供给顺序 = 注册表顺序，建模侧依赖其稳定性，勿随机排序 |
