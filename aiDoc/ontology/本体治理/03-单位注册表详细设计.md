## 一、功能概述

### 1.1 功能定位

单位注册表以 **QUDT 单位 IRI 为规范身份**，治理"量纲 → 单位"两级资产：量纲（QuantityKind，Length/Mass/…，**只读**，随迁移种子分发）下挂单位（Unit），每个单位携带相对基准单位的线性换算参数（`conversionMultiplier` 乘数 + `conversionOffset` 偏移，温度类需要），供：

1. 治理员维护单位（CRUD + 停用/启用）与换算试算；
2. 建模侧经供给接口拉取单位清单（含换算系数）与换算能力；
3. 属性模板的 `unitRef` 预设单位联动生效（datatype 属性带预设 QUDT 单位 IRI）。

### 1.2 功能范围

**含**：
1. 量纲只读列表（`getQuantityKindList`，供左树/下拉）；
2. 单位全栈 CRUD（分页、详情、创建、更新、删除）+ 停用/启用（status toggle）；
3. 单位换算 `convertUnit(value, fromIri, toIri)`：同量纲返回结果，跨量纲返回 `result=null + reason`（不报错）；
4. 高精度：PG `numeric(30,15)` ↔ Go `shopspring/decimal`（**从 indirect 提升为直接依赖**），禁用 float64 运算；
5. 供给接口：`/supply/v1/units`（按量纲过滤，含换算系数）+ `/supply/v1/units/convert`；
6. 前端：左量纲树 + 右单位列表 + 换算试算面板（debounce 300ms）。

**不含**：QUDT TTL 参考本体浏览/导入（贯穿）、注释属性（04）。

### 1.3 与参考设计的差异裁定（以前端实现为准 + 参考文档勘误）

| # | 参考设计/种子 | 采用口径 | 裁定说明 |
|---|---|---|---|
| 1 | M3 设计 disable 仅置 status=1 | disable 为**幂等双向切换**（0↔1），按钮文案"停用/启用" | 与 01 的弃用 toggle 同模式，落库字段为 status |
| 2 | M0 V11 种子 `DEG_F offset=-32.0`、`K offset=273.15` | **修正为自洽参数**（见 §3.5） | 按参考种子参数验算 100°C→K 得 -173.15、32°F→C 得 -14.2，与其自身 AC 矛盾；换算模型要求**同量纲所有单位相对同一隐式基准**，本设计统一以摄氏度为温度基准重标定 |
| 3 | 换算试算面板前端本地计算（PRD NFR-15） | 前端调后端 `/convert`，**debounce 300ms** | 前端 float 运算精度不安全；debounce 满足 NFR-15 交互诉求 |
| 4 | 量纲树用 a-tree | 本项目用 el-tree（Element Plus） | 组件库适配，交互不变（虚拟根"全部量纲" + 叶子=量纲） |
| 5 | 换算系数前端 `precision: 15` | 保留 | InputNumber precision 15，与 numeric(30,15) 对齐 |
| 6 | keyword 匹配 unitCode/label/labelCn/symbol | 一致 | 无冲突 |

## 二、术语与业务规则

| 术语 | 含义 |
|---|---|
| quantityKindCode | 量纲标识（如 `Length`/`Mass`），单位经此软引用量纲（不建物理外键） |
| qudtIri | QUDT 单位 IRI（如 `http://qudt.org/vocab/unit/KiloGM`），**换算与供给的定位键**，全局唯一 |
| unitCode | 单位标识（如 `KiloGM`），全局唯一 |
| conversionMultiplier / conversionOffset | 相对量纲内隐式基准单位的线性换算参数：`基准值 = 数值 × multiplier + offset` |
| scalingOf | 基准单位 qudtIri（派生关系留痕，如 KiloM → M） |
| ucumCode | UCUM 标准编码（如 `kg`），互操作备用 |
| qudtVersion | QUDT 版本快照（如 `3.1.5`），symbol 冗余存储，IRI 漂移时降级可用 |

**核心业务规则**：

1. **双唯一**：qudtIri、unitCode 各自全局唯一（部分唯一索引 + Service 校验，编辑排除自身）；
2. **量纲存在校验**：创建/更新单位时 quantityKindCode 必须存在于 `ont_quantity_kinds`；
3. **builtin 保护**：builtin 单位不可编辑/删除（unitCode 编辑时禁用），**可停用**；
4. **换算规则**：`result = (value × from.multiplier + from.offset − to.offset) ÷ to.multiplier`；跨量纲或单位不存在 → `result=null, reason="quantity kind mismatch or unit not exists"`（HTTP 仍 200）；
5. **停用语义**：status=1 的单位不出现在供给与下拉（治理列表仍可见、可筛选）；
6. **量纲只读**：量纲是 QUDT 既定集合，治理员只维护单位，无量纲 CRUD。

| unitCode | symbol | label_cn | 量纲 | multiplier | offset | scalingOf |
|---|---|---|---|---|---|---|
| M / CentiM / MilliM / KiloM | m/cm/mm/km | 米/厘米/毫米/千米 | Length | 1 / 0.01 / 0.001 / 1000 | 0 | — / M / M / M |
| KiloGM / GM / MilliGM | kg/g/mg | 千克/克/毫克 | Mass | 1 / 0.001 / 0.000001 | 0 | — / KiloGM / KiloGM |
| SEC / MIN / HR | s/min/h | 秒/分/时 | Time | 1 / 60 / 3600 | 0 | — / SEC / SEC |
| **DEG_C / DEG_F / K** | °C/°F/K | 摄氏度/华氏度/开尔文 | Temperature | **1 / 0.555555555555555 / 1** | **0 / −17.7777777777778 / −273.15** | — / DEG_C / DEG_C |
| M2 / FT2 / HECTARE | m²/ft²/ha | 平方米/平方英尺/公顷 | Area | 1 / 0.09290304 / 10000 | 0 | — / M2 / M2 |
| M3 / L / CM3 | m³/L/cm³ | 立方米/升/立方厘米 | Volume | 1 / 0.001 / 0.000001 | 0 | — / M3 / M3 |
| USD / CNY / EUR | $/¥/€ | 美元/人民币/欧元 | Currency | 1 / 0.14 / 1.08 | 0 | 参考汇率（非实时，注释标注） |
| BYTE / KiloBYTE / MegaBYTE | B/KB/MB | 字节/千字节/兆字节 | DataQuantity | 1 / 1024 / 1048576 | 0 | — / BYTE / BYTE |

> **温度参数勘误说明（重要）**：参考 M0 V11 种子（DEG_F offset=-32、K offset=273.15）与其 M3 换算公式不自洽（验算 100°C→K = (100×1+0−273.15)/1 = −173.15，与 AC 期望 373.15 矛盾）。本设计以"摄氏度为温度量纲隐式基准"重标定：DEG_C(1, 0)、DEG_F(5/9, −459.67×5/9=−17.7777777777778)、K(1, −273.15)。自洽性验算：
> - 32°F→°C：(32×0.555555555555555 − 17.7777777777778 − 0) ÷ 1 = **0** ✓
> - 100°C→K：(100×1 + 0 − (−273.15)) ÷ 1 = **373.15** ✓
> - 373.15K→°F：(373.15×1 − 273.15 − (−17.7777777777778)) ÷ 0.555555555555555 = **212** ✓
>
> 货币 multiplier 为参考汇率快照（R-7：非实时，仅治理演示与换算链演示用）。

### 4.2 Service 层关键逻辑

CRUD 与 01 同范式（builtin 保护 / 双唯一校验 / 量纲存在校验 / source 强制 custom / operator 审计），仅列差异与换算核心：

```go
type UnitService struct{}

// ConvertValue 单位换算（FR-3 核心）：同量纲返回结果；跨量纲/单位不存在返回 (nil, nil)
func (s *UnitService) ConvertValue(value decimal.Decimal, fromIri, toIri string) (*decimal.Decimal, error) {
	var from, to ontology.OntUnit
	if err := global.GVA_DB.Where("qudt_iri = ?", fromIri).First(&from).Error; err != nil {
		return nil, nil // 单位不存在 → 不可换算（不报错）
	}
	if err := global.GVA_DB.Where("qudt_iri = ?", toIri).First(&to).Error; err != nil {
		return nil, nil
	}
	if from.QuantityKindCode != to.QuantityKindCode {
		return nil, nil // 跨量纲 → 不可换算
	}
	if fromIri == toIri {
		return &value, nil
	}
	// result = (value × from.mult + from.offset − to.offset) ÷ to.mult，15 位小数 HALF_UP
	fm, fo := nullSafeOne(from.ConversionMultiplier), nullSafeZero(from.ConversionOffset)
	tm, to2 := nullSafeOne(to.ConversionMultiplier), nullSafeZero(to.ConversionOffset)
	base := value.Mul(fm).Add(fo)
	res := base.Sub(to2).DivRound(tm, 15) // decimal.RoundHalfUp
	return &res, nil
}
```

### 6.5 换算试算面板

```vue
<template>
  <el-card shadow="never" class="convert-panel">
    <span class="title">单位换算试算</span>
    <el-input-number v-model="value" :precision="15" :step="1" style="width: 160px" />
    <el-select v-model="fromIri" filterable :options="unitOptions" placeholder="选择源单位" style="width: 220px" />

</template>
```

- `unitOptions`：`getUnitAll()` 全量（不按量纲过滤），option label `` `${label}（${symbol || unitCode}）` ``、value=qudtIri，filterable 前端包含匹配；
- **防抖 300ms**：`watch([value, fromIri, toIri])` 清旧 timer 后 300ms 执行；三项任一未选/为空直接置 `result='--'` 不发请求；
- 响应处理：`res.result !== null` → 显示数值（trim 尾零）；`null` → `result='无法换算'` + 红字展示 `reason`。

## 十、风险与注意事项

| # | 风险/注意 | 应对 |
|---|---|---|
| 1 | **温度 offset 勘误** | 必须按 §3.5 参数种入；联调以三组验算值（0/373.15/212）为准；勿照抄参考 V11 种子 |
| 2 | **禁用 float64** | 换算链路（Service/请求绑定/JSON）全用 `decimal.Decimal`；仅前端展示层用 number（precision 15） |
| 3 | **decimal JSON 序列化** | 默认输出数字；超大/超高精度值科学计数法风险 → 乘数/偏移约束 ≤15 位小数（numeric(30,15)），前端 InputNumber precision 15 双重约束 |
| 4 | **除零** | multiplier 理论非零；Service 侧 nullSafeOne 把空值当 1，显式 0 值在 DivRound 前校验（为 0 返回不可换算 reason="invalid multiplier"） |
| 5 | **货币非实时** | 货币 multiplier 为参考汇率快照；面板可加"参考汇率"角标提示（可选） |
| 6 | **量纲只读边界** | 不提供量纲 CRUD 路由/API/casbin 条目；扩充量纲走新迁移种子 |
| 7 | **unitRef 软引用** | 属性模板 unitRef 不建外键、不做强校验（单位可后建）；03 交付后前端把 unitRef 输入升级为按量纲过滤的单位下拉（01 表单的可选增强） |
| 8 | **换算面板全量下拉** | `getUnitAll` 返回全量启用单位（预期 ≤ 数百）；超千级时改为按量纲级联过滤 |
