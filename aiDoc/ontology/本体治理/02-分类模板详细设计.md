## 一、功能概述

### 1.1 功能定位

分类模板是治理侧的"类分类树"：以**多棵分类树**（treeRoot 标识，如 `equipment`）组织可复用的类模板。每个分类模板节点携带：

- **外观**：icon（emoji/图标类名）+ color（hex），可继承父级（inheritAppearance）；
- **结构骨架**：子表引用属性模板（propertyTemplateCode + refType + sortOrder），节点间**父子继承**（子节点继承父链全部骨架引用，同名覆盖）；
- **规范分类编码**：按编码规则自动生成（如 `30-01-01`），也可手动覆盖（校验前缀一致）。

分类模板是**纯治理资产，不产生任何 RDF 序列化字段**（边界：本功能不创建 `owl:Class`）；建模侧通过供给接口拉取分类树，拖拽/挂载后以 `templateRef` 溯源。

### 1.2 功能范围

**含**：
1. 分类模板树 CRUD（扁平存储 + 物化路径，参照本项目公司/部门模块范式）；
2. 分页列表（普通分页表 + 富化字段 parentLabel/treeRootLabel/hasChildren）；
3. 分类树根下拉（tree-roots 接口）；
4. 分类编码规则配置（find/save）+ 编码自动生成/预览（preview-code）；
5. 结构骨架子表（保存随主表提交，增量同步，禁 delete-then-recreate）；
6. 树维护（改父重算子树路径、环路检测、层级上限、删子保护）；
7. 继承视图接口（预留，本期前端无入口）、弃用接口（预留）；
8. 供给接口：分类模板树（`/supply/v1/classTemplate/tree`）+ 类层级建议（`/supply/v1/classHierarchy/suggest`）；
9. `ont_class_hierarchies` 表建表预留（本期不实现同步，FR-9 边界）。

**不含**：单位（03）、注释属性（04）、Brick 参考本体导入（贯穿，导入时映射 parentId 不写 hierarchy 表）。

### 1.3 与参考设计的差异裁定（以前端实现为准）

| # | 芋道 M2 设计 | 前端实现（**采用**） | 裁定说明 |
|---|---|---|---|
| 1 | 列表页为 **vxe 树表**（treeConfig transform + 不分页） | 列表页为**普通分页表**（默认 pageSize 100，可选 50/100/200/500），列含层级/父级/分类树富化字段 | 采用分页平铺；树形选择器仅在表单"父节点"处使用（el-tree-select + 扁平数据前端组树） |

| 8 | 搜索字段：classificationCode（右模糊）+ name + treeRoot | 同 | 一致，无冲突 |

## 二、术语与业务规则

| 术语 | 含义 |
|---|---|
| treeRoot | 分类树标识（如 `equipment`），支持多棵树并存；同一 treeRoot 下编码唯一 |
| parentId / parentPath | 父节点 ID（根=0）；物化路径 `"0,{祖父},{父},"`（**含父链、不含自身**），如 `"0,12,35,"` |
| treeLevel | 层级，根=0；**上限 3**（四级） |
| classificationCode | 规范分类编码（如 `30-01-01`），按规则生成或手动覆盖（须与父编码前缀一致） |
| templateCode | 节点唯一人类可读标识（如 `spray-pump`），与 classificationCode 并存均可查询 |
| 结构骨架（refs） | 子表 `ont_class_template_refs`：节点引用的属性模板清单（propertyTemplateCode + refType property/relationship + sortOrder） |
| 继承 | 结构骨架继承：子节点供给视图 = 父链全部引用 + 本节点追加（同名覆盖）；外观继承：inheritAppearance=1 时取最近非空父 icon/color |
| source 三态 | 供给视图属性来源标记：`node`（本节点声明）/ `inherited`（继承而来）/ `overridden`（覆盖父级同名） |

**核心业务规则**：

1. **builtin 保护**：source='builtin' 不可编辑/删除（后端校验 + 前端隐藏按钮）；
2. **删除保护**：存在子节点（hasChildren）时拒绝删除，提示先删子级；删除主表时级联软删骨架子表；
3. **环路检测**：设置父节点时，新父的 parentPath 不得包含自身 ID（O(1) 字符串包含判断）；不得以自身为父；
4. **层级上限**：四级（新节点 treeLevel = parent.treeLevel + 1 ≤ 3）；
5. **骨架引用校验**：保存时校验 propertyTemplateCode 在属性模板库中存在（含 builtin/custom、含弃用），不存在返回业务错误（不静默）；
6. **编码规则**：根节点编码 = baseNumber（如 30）；子节点 = 父编码 + 分隔符 + 零填充同级序号（如 `30-01-01`）；序号 = 同级现有子节点数 + 1（并发重复由唯一索引兜底）；改规则只影响新节点，存量编码冻结；
7. **编码唯一**：(treeRoot, classification_code) 部分唯一索引；手动覆盖时校验唯一 + 前缀一致（`父编码 + 分隔符` 前缀）；
8. **改父移动**：事务内更新自身 path/level 后，子树 `parent_path` 前缀 REPLACE + `tree_level` 增量平移（一条 UPDATE）。

#### （a）树维护：validateAndFillTree + 子树批量平移

```go
const MaxTreeLevel = 3 // 上限四级（0~3）

// validateAndFillTree 校验父链并填充 parent_path/tree_level（参照 sys_company.resolveCompanyParent）
func (s *ClassTemplateService) validateAndFillTree(tx *gorm.DB, t *ontology.OntClassTemplate) error {
	if t.ParentId == 0 { // 顶级
		t.ParentPath, t.TreeLevel = "0,", 0
		return nil
	}
	if t.ParentId == t.ID { return errors.New("不能以自身为父节点") }
	var parent ontology.OntClassTemplate
	if err := tx.First(&parent, t.ParentId).Error; err != nil { return errors.New("父分类模板不存在") }
	// 环路检测：新父的祖先链（含父）不能包含自身 —— O(1) 物化路径包含判断
	selfID := "," + strconv.FormatUint(uint64(t.ID), 10) + ","
	if t.ID > 0 && strings.Contains(","+parent.ParentPath, selfID) {
		return errors.New("不能将自身或后代节点设为父节点（成环）")
	}
	if parent.TreeLevel+1 > MaxTreeLevel { return errors.New("分类模板层级最多四级") }
	t.ParentPath = parent.ParentPath + strconv.FormatUint(uint64(parent.ID), 10) + ","
	t.TreeLevel = parent.TreeLevel + 1
	return nil
}

// moveSubtree 改父后批量平移子树（一条 UPDATE，参照 sys_company 移动逻辑）
func (s *ClassTemplateService) moveSubtree(tx *gorm.DB, id uint, oldPath string, newParent *ontology.OntClassTemplate) error {
	oldSelf := oldPath + strconv.FormatUint(uint64(id), 10) + ","            // 移动前自身完整路径
	newSelf := newParent.ParentPath + strconv.FormatUint(uint64(newParent.ID), 10) + "," + strconv.FormatUint(uint64(id), 10) + ","
	delta := newParent.TreeLevel + 1 - int(oldSelfLevel)                    // 层级差（oldSelfLevel 为移动前自身 level）
	return tx.Model(&ontology.OntClassTemplate{}).
		Where("parent_path LIKE ?", oldSelf+"%").
		Updates(map[string]interface{}{
			"parent_path": gorm.Expr("REPLACE(parent_path, ?, ?)", oldSelf, newSelf),
			"tree_level":  gorm.Expr("tree_level + ?", delta),
		}).Error
}
```

> 与芋道版"递归逐层 refreshChildrenPath"的差异见 §1.3-5；算法与本项目 `sys_company.go` 完全同构（含 `REPLACE` 批量 + level 平移），已被公司模块验证。

func (s *ClassTemplateService) CreateClassTemplate(t *ontology.OntClassTemplate, operator string) error {

	return global.GVA_DB.Transaction(func(tx *gorm.DB) error {

func (s *ClassTemplateService) UpdateClassTemplate(t *ontology.OntClassTemplate, operator string) error {
	var existing ontology.OntClassTemplate
	if err := global.GVA_DB.First(&existing, t.ID).Error; err != nil { return errors.New("分类模板不存在") }
	if existing.Source == "builtin" { return errors.New("内置分类模板不可编辑") }
	if err := s.validateTemplateCodeUnique(t.TemplateCode, t.ID); err != nil { return err }
	if err := s.validateAndFillTree(global.GVA_DB, t); err != nil { return err }
	if err := s.validateRefCodes(t.OntClassTemplateRefs); err != nil { return err }
	if t.ClassificationCode != "" {
		if err := s.validateClassificationCode(t); err != nil { return err }
	}
	return global.GVA_DB.Transaction(func(tx *gorm.DB) error {
		if err := tx.Model(&ontology.OntClassTemplate{}).Where("id = ?", t.ID).Updates(map[string]interface{}{
			"template_code": t.TemplateCode, "classification_code": t.ClassificationCode, "label": t.Label,
			"label_cn": t.LabelCn, "description": t.Description, "tree_root": t.TreeRoot,
			"parent_id": t.ParentId, "sort": t.Sort, "icon": t.Icon, "color": t.Color,
			"inherit_appearance": t.InheritAppearance, "deprecated": t.Deprecated, "updated_by": operator,
		}).Error; err != nil { return err }
		if err := s.syncRefs(tx, t.ID, t.OntClassTemplateRefs); err != nil { return err }
		if existing.ParentId != t.ParentId { // 改父：批量平移子树
			return s.moveSubtree(tx, t.ID, existing.ParentPath, /*新父*/)
		}
		return nil
	})
}

// syncRefs 骨架子表增量同步（按 ID diff：更新/新增/删除，禁止 delete-then-recreate）
func (s *ClassTemplateService) syncRefs(tx *gorm.DB, templateID uint, newList []ontology.OntClassTemplateRef) error {
	var oldList []ontology.OntClassTemplateRef
	if err := tx.Where("class_template_id = ?", templateID).Find(&oldList).Error; err != nil { return err }
	oldByID := map[uint]ontology.OntClassTemplateRef{}
	for _, o := range oldList { oldByID[o.ID] = o }
	newIDs := map[uint]bool{}
	for i := range newList {
		n := &newList[i]
		n.ClassTemplateId = templateID
		if n.ID > 0 { // 更新既有行
			newIDs[n.ID] = true
			if err := tx.Model(&ontology.OntClassTemplateRef{}).Where("id = ?", n.ID).
				Updates(map[string]interface{}{"property_template_code": n.PropertyTemplateCode,
					"ref_type": n.RefType, "sort_order": n.SortOrder}).Error; err != nil { return err }
		} else { // 新增行
			n.ClassTemplateId = templateID
			if err := tx.Create(n).Error; err != nil { return err }
			newIDs[n.ID] = true
		}
	}
	for _, o := range oldList { // 删除被移除的行（软删）
		if !newIDs[o.ID] {
			if err := tx.Delete(&ontology.OntClassTemplateRef{}, o.ID).Error; err != nil { return err }
		}
	}
	return nil
}

// GenerateClassificationCode 根节点=baseNumber；子节点=父编码+分隔符+零填充序号
func (s *ClassificationRuleService) GenerateClassificationCode(parentId uint, treeRoot string) (string, error) {
	rule := s.getRuleOrDefault(treeRoot) // 无规则时默认 {separator:"-", levelDigits:2, baseNumber:1, zeroPad:1}
	if parentId == 0 { return strconv.Itoa(rule.BaseNumber), nil }
	var parent ontology.OntClassTemplate
	if err := global.GVA_DB.First(&parent, parentId).Error; err != nil { return "", errors.New("父分类模板不存在") }
	var count int64
	global.GVA_DB.Model(&ontology.OntClassTemplate{}).Where("parent_id = ?", parentId).Count(&count)
	seq := int(count) + 1
	suffix := strconv.Itoa(seq)
	if rule.ZeroPad == 1 { suffix = fmt.Sprintf("%0"+strconv.Itoa(rule.LevelDigits)+"d", seq) }
	return parent.ClassificationCode + rule.Separator + suffix, nil
}

## 十、风险与注意事项

| # | 风险/注意 | 应对 |
|---|---|---|
| 1 | **编码序号并发** | `同级计数+1` 在并发新增时可能撞号：治理场景低频可接受，(treeRoot,code) 唯一索引兜底（冲突报错重试）；高频化后再引入行锁/序列 |
| 2 | **moveSubtree 的 oldSelf level** | 平移 delta 需用移动前自身 tree_level（从 existing 读），勿用校验后的新值；单测覆盖跨层移动 |
| 3 | **骨架 diff 禁 delete-then-recreate** | syncRefs 按 ID 增量同步；子表行 ID 由前端编辑回填携带（新增行 ID=0） |
| 4 | **删除分类模板的骨架级联** | 仅软删本级 refs；被 01 删除校验依赖的 `idx_ont_class_tpl_ref_code` 反查索引已在 DDL 中建 |
| 5 | **parent_path 长度** | varchar(767)：四级路径最长 `"0,"+3×(bigint+逗号)`，充足；勿缩 |
| 6 | **继承视图查询次数** | 祖先链一次 IN + refs 一次 IN（全链 class_template_id），共 2 次 DB 访问，无 N+1；如成为热点再加进程内缓存（TTL 5min，模板写入时失效） |
| 7 | **treeRootLabel 取值口径** | 取该树 tree_level=0 且 sort/id 最小的根节点 label；一树多根时仅取首根展示（树本身允许多根） |
| 8 | **预留接口交付口径** | inherited/disable/规则表单 UI/建议接口本期实现后端能力、不承诺前端入口；swagger 注释标注"预留"避免误删 |
| 9 | **ont_class_hierarchies 空表** | 仅建表；勿注册 RegisterTables 之外的任何读写逻辑（防边界漂移） |
| 10 | **改 treeRoot（换树）** | 本期禁止通过更新修改 tree_root（子树编码/规则绑定原树）；Update 校验 treeRoot 与存量一致，换树走"新建+废弃" |
