## 1. 总体策略与原则

1. **先立框架，再动页面**：M0 先把 `useGvaGrid + GvaGrid` 封装、高度方案、主题适配做稳并用 demo 页验证，之后所有页面迁移都是"机械翻译"，风险前置。
2. **试点先行，固化 SOP**：用 `user.vue`（最典型）与 `api.vue`（多选 + 导入导出 + 下拉搜索，覆盖面最广）做试点，沉淀迁移 SOP（附录 A）后再批量铺开。
3. **小步提交，按批合并**：每批页面一个 PR，出问题可整体回滚该批；新旧表格共存期内互不干扰（样式作用域隔离，见设计 §19 R9）。
4. **复杂页面最后攻坚**：`autoCode/index.vue`（20 列、拖拽、多区联动）排在全部常规页之后单独处理，不阻塞主线。
5. **生成器同步收口**：页面迁完前不改生成器模板，避免"迁了一半、生成器又在产出旧模式"的两头维护窗口拉长；M3 一次性切换并回归生成链路。
6. **不追求一次性 100%**：dashboard 两个静态表等非列表场景明确不迁（设计 §18），避免为覆盖率而做负收益迁移。

## 6. 分支与协作规范

| 项 | 约定 |
| --- | --- |
| 主分支 | `feature/vxe-grid`（自 `main` 拉出），里程碑完成后**逐里程碑**合入 `main`（M0+M1 可合并为首个 PR） |
| 提交粒度 | 一个任务一个 commit，message 前缀：`feat(gvaGrid):` / `refactor(superAdmin):` / `chore(deps):` |
| PR 粒度 | M0+M1 一个 PR；B1/B2/B3+B4/B5 各一个 PR；M3 一个 PR；每个 PR 必附附录 B 自测结果（截图或清单勾选） |
| Code Review | 至少 1 人；B 批 PR 重点看：删除的旧逻辑是否被封装等价吸收（尤其排序、删除刷新、空页回退） |
| 冲突预防 | 迁移期间避免与页面功能改动并行同一文件；确需并行，页面迁移 PR 优先合并 |
| 回滚 | 每批独立 PR，出问题 revert 单批；`components/gvaGrid` 目录无反向依赖，可整体下线 |
| 文档 | 设计变更（如 R7 参数差异）当日回写 `aiDoc/vxegrid/01-详细设计方案.md` 的"实现注记"；本计划的批次状态表每周更新 |

## 附录 A：页面迁移 SOP

> 顺序执行，每步有验收动作。来源：设计文档 §16.2，M1 试点后如需修订，以试点结论为准并同步更新设计文档。

1. **读旧页**：列出该页的查询条件、列、按钮、特殊交互（树/拖拽/导入导出）清单；
2. **搭骨架**：`useGvaGrid({ id: '模块-页面', api, columns, searchItems, defaultSort, checkbox })`，列按设计 §10.2 映射表机械翻译（prop→field、label→title、min-width→minWidth、sortable="custom"→sortable: true、fixed、模板列→slots）；
3. **查询区**：input→`$input`、静态 select→`$select`、字典→`gvaDictSelect`、日期范围→`gvaDateRange`；复杂条件（远程搜索/级联）保留 `itemRender: { name: 'slot' }` + 模板插槽写 el 组件；
4. **工具栏**：`gva-btn-list` 按钮原样搬入 `#toolbar-buttons`（保留 `v-auth` / `btns` 判断）；批量删除接 `useGvaGridDelete`；
5. **单元格**：日期列加 `cellRender: { name: 'gvaDate' }`；头像→`gvaImage` 或插槽；字典→`gvaDict`；操作列→插槽（推荐）或 `gvaOperate`；
6. **删旧代码**：六件套状态与函数（searchInfo/page/pageSize/total/tableData/orderKey/desc、onSubmit/onReset/handleSizeChange/handleCurrentChange/sortChange/getTableData、删除确认样板）；模板删 gva-search-box/gva-table-box/gva-btn-list/gva-pagination；
7. **自测**：跑附录 B checklist，全项勾选后提 PR。

## 附录 B：单页回归 Checklist

```
□ 首次加载自动查询，默认排序（orderKey/desc）与旧版一致
□ 查询：条件生效且回第 1 页
□ 重置：清空条件回第 1 页（含隐藏默认值恢复 searchDefaults）
□ 分页：翻页、改每页条数（10/30/50/100）、跳页；total 正确
□ 排序：各可排列表头 升/降 切换，请求参数为蛇形 orderKey + desc
□ 选择：勾选/全选/跨页保留；批量删除按钮 disabled 联动
□ 新增：成功后列表刷新（reload/refresh 语义与旧版一致）
□ 编辑：抽屉/弹窗打开与保存正常，列表数据更新
□ 删除：确认框文案与类型一致；成功提示；删除后刷新；末页删空自动回退
□ 单元格：日期/字典/头像/标签/自定义插槽渲染与旧版一致
□ 工具栏：业务按钮及 v-auth 权限显隐正确；导入导出组件可用（如该页有）
□ 表格配置：列设置显隐/顺序/固定生效并持久化（刷新页面保留）；密度切换；全屏进出正常；刷新按钮保持当前页
□ 高度：首载/窗口拖拽/侧栏折叠/tabs 切回/搜索折叠展开，高度正确无跳动
□ 主题：暗色模式正常（含列设置弹层）；主色切换联动
□ 异常：接口报错有空态无白屏；空数据空态正常
□ 残留：本文件已无 el-table / el-pagination / gva-search-box / gva-table-box
```
